## 2. 賛否公表の粒度（実物で確定）

**結論: 会派別の態度が、採決された全案件について公式公表されている（確定）。議員個人別の公表はなし。**

### 2-1. 記号体系と記載範囲

- 3種の結果 PDF すべてに「各会派の態度（○は賛成、×は反対）」の欄があり、**採決された案件の全件**に9会派分の ○／× が印字される。全会一致の議案も含め全件一律の公表であり、賛否が分かれた案件のみの抜粋形式ではない（段階0の見込みどおり）。
- 段階0で「●／×」とされた記号は、実物では **○（賛成）／×（反対）** である（表頭の凡例で確定）。
- 記号行の実測（座標解析）: 議案36件すべてに9会派分の記号行が存在（36行）。意見書案4件すべてに9会派分（4行）。請願は第35号に1行、第36号に **2行**（下記 §3）。
- **報告には態度欄の記号は印字されない**（「議決不要」「継続審査」の結果表示のみ）。報告37件には faction_votes を作らない。
- 賛否が分かれた議案は9件: 共産のみ反対 6件、民主のみ反対 2件、民主・摂津が反対 1件（第36号 上告の件）。意見書案は4件とも全会派賛成。

### 2-2. 座標レベルの照合要否

- 記号は **テキスト層の実グリフ**（MS-Mincho）で、各会派列の x 座標が全ページで固定（維新 575.0／公明 601.8／自民 628.5／民主 655.3／共産 682.1／大阪 708.8／未来 735.6／摂津 762.3／繋ぐ 789.1、単位 pt）。列の対応付けは x 座標で決定的に判定できることを本調査で実測した。
- したがって登録時の抽出は「pdftotext の出現順」ではなく **座標ベースの列割り当て** を正とし、Word 版を第二系統として突き合わせる設計とする（愛知・名古屋・札幌で確立した座標照合の原則と同型）。

### 2-3. 採決の方法・単位

- 議案は群単位で一括採決される運用（10月20日は議案第1〜32号・第34・35号が一括、第33号は単独、という進行が議事資料・中継タイトルからうかがえる）。議案別の採決方法（起立／簡易等）は議会運営委員会資料「採決順序及び採決方法」が会期ごとに公表されており、登録時に method を記録する場合は同資料で確認する（本棚卸しでは未取得。§10）。
- 会派の態度は「採決に先立つ議会運営委員会で確認した態度」ではなく **議決結果表に併記された確定結果** である（愛知県議会の態度 PDF が「採決前の確認態度」であったのとは性質が異なる）。

### 2-4. 議員個人別

- 記名投票結果等の議員個人別の一覧公表は確認できなかった（探した場所: 結果 PDF 群、本会議ページ、府議会だより、会議録検索システムの案内）。議員個人別投票は「公表なし（not_published）」として登録する。

## 4. 政務活動費

### 4-1. 制度（公式ページ・条例で確認）

- 根拠: 大阪府政務活動費の交付に関する条例。交付は **会派と議員個人の二層**。議員1人当たり月額59万円の枠を、会派分（59万円から会派が定める議員個人分月額を減じた額 × 所属議員数）と議員個人分に分けて交付する。
- 報告・公開: 議長は収支報告書・会計帳簿等の写しをインターネットで公表する（条例第12条第4項。適用は平成26年度分以降）。平成27年（2015年）7月30日から、**領収書を含めた全ての提出書類** を公開。
- 書類の範囲: 収支報告書、会計帳簿、支払明細書、活動記録簿、事務所状況報告書、職員雇用状況報告書、領収書。
- 保存・閲覧: 収支報告書等は5年分保存され、府議会情報コーナー（府庁本館5階）で閲覧可能。

### 4-2. 専用ポータルの形式（実測）

- ポータル: https://www.seikatu.pref.osaka.lg.jp/ （府議会サイトからリンクされる専用サイト）
- 検索形式: 年度（セレクト）× 会派検索／議員名検索の **AJAX POST** 形式。エンドポイントは `asearch_k.php`（会派検索、引数 y・k・kn）と `asearch_n.php`（議員名検索、引数 y・k）で、結果は HTML 断片で返る。**通常の curl POST で結果を取得できることを本調査で実測した**（ブラウザ操作は不要）。
- 年度の選択肢: 令和3年度〜令和8年度＋「令和5年4月」（任期替わりの端数月。現行ポータルのトップの選択肢はここまで。令和2年度以前の到達経路は §10）。
- 結果の単位: 単位（会派／議員）ごとに2ファイル — **「会計帳簿等」PDF**（収支報告書・会計帳簿・支払明細書・活動記録簿・事務所状況報告書・職員雇用状況報告書を収録）と **「領収書」PDF**。URL は `pdf/{年度コード}-{単位コード}-{a|b}.pdf` の決定的なパターン（a=会計帳簿等、b=領収書）。
- **令和7年度分の実測**: 全会派検索で 会派単位9件（維新・公明・自民・民主・共産・大阪なにわの和・未来・摂津・躍進大阪。「（無所属）」は単位としての書類なし）＋議員単位80件 ＝ **89単位 × 2ファイル（179リンク）**。
- ファイルはスキャン画像で巨大（会計帳簿等で最大約141MB、領収書で最大約142MB）。一括ダウンロードは帯域・容量の計画が要る。
- 会派名は「各年度の最終交付月」のものが使われる（ポータル注記）。令和7年度分の会派名は「大阪なにわの和」（9月定例会の結果表の「大大阪の和」とは時点により異なる。§6-2）。
- 年度途中の公開もある: 令和8年7月22日付けで辞職した議員の令和8年度分収支報告書等が2026年11月20日に公開開始された（府議会トップの新着情報で確認）。令和8年度分は年度進行中のため登録対象にしない。

### 4-3. 登録単位と範囲の設計案

- **登録単位**: 公式公開の単位に一致させ、**会派単位＋議員個人単位の両層** を登録する（愛知県議会の前例＝令和7年度分103件と同型）。
- **登録範囲（第一弾）**: 直近の完結年度である **令和7年度（FY2025）分: 89単位**（会派9＋議員80）。各単位の収支報告書から 交付額・支出内訳（費目別）・残額（返還額）を登録する（愛知の political_activity_expenses の形式＝ granted_yen＋費目別 breakdown を踏襲）。
- 領収書 PDF（b）は個別登録せず、公開されている事実と URL パターンを disclosure profile に記録する（北海道の「集計＋制度のみ」とも、愛知の「報告書の金額まで登録」とも異なる中間形ではなく、金額登録は a の収支報告書に基づく。領収書そのものの明細登録は行わない）。
- 抽出方法: a PDF はスキャン画像のため、収支報告書のページ（各単位の先頭部）を描画画像で目視確認するか OCR を補助に使い、**金額は必ず画像の印字で検証する**（テキスト抽出はできない前提）。
- 拡張（任意・第二弾以降）: 令和6年度・令和5年度分（現任期分）。「令和5年4月」は前任期の端数月のため現任期の登録範囲には含めない。
- ファイル取得は AJAX エンドポイントへの POST で単位一覧を確定させ、URL パターンで直接ダウンロードする（検索フォームの画面遷移を模す必要はない）。

## 6. 任期・定数・会派構成

### 6-1. 任期の裏取り（日単位で公式明記あり）

- 任期: **2023年4月30日 〜 2027年4月29日（4年）**。
- 根拠1: 府議会公式 FAQ「府議会議員の任期について教えてください。」に開始日・満了日とも日単位で明記（段階0で確認）。

## 7. 抽出上の注意点（登録作業の難所）

1. **記号の列割り当ては座標で確定する**（§2-2）。pdftotext -layout の出現順でも概ね整うが、正は x 座標の列位置とする。
2. **請願第36号の項目別採決**: 1件の請願に2組の会派態度がある。単一の態度セットを流し込むと誤登録になる（§8 の設計で吸収する）。
3. **報告の「議決不要」と「継続審査」の区別**: 結果欄の文言どおりに登録する。決算18件は認定の結論ではない（「継続審査」を outcome の確定として扱わない。北海道の前例どおり状態として登録し、結論が出た会期で更新する）。
4. **会派名の時点差**: 結果表（会期時点）と政活費ポータル（年度の最終交付月時点）で会派名が異なる場合がある（大大阪の和／大阪なにわの和）。それぞれ出典の表記どおりに記録し、同一視の判断は証拠パケットに明記する。
5. **意見書案 PDF の所在**: 会期ページのリンク先は documents/139220/ikensyo0809_2.pdf。documents/62646/ikensyo0809.pdf と同一内容（MD5 一致を確認）。出典カタログには会期ページからのリンク先を正として記録する。
6. **政活費 PDF の容量**: 単位あたり最大約140MB。89単位×2ファイルの一括取得は数GB規模になりうる。金額登録に必要なのは a（会計帳簿等）の収支報告書ページのみで、b（領収書）は取得自体を省略できる（公開事実の記録で足りる）。
7. 議案の概要欄には外部リンク（予算概要ページ等）が含まれるが、登録に必要なのは件名・概要・採決日・結果・態度であり、リンク先の内容は対象外。
