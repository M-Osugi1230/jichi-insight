- **「主な議案」の選定基準の公式明記は確認できなかった**。索引ページの説明は「各定例会の主な議案に対する会派等の賛否一覧がご覧いただけます」のみで、選定は議会局の運用判断とみられる。実物の傾向は §2-3。
- **議員個人別の賛否は公表なし**（段階0の結論を維持）。本会議場には令和6年4月から電子採決システムが導入されているが、個人別結果の Web 公表は確認できなかった。
- **政務活動費は「会派分＋議員分」の二層が両方 Web 公開** されている。現行のインターネット公開索引で到達できるのは **令和5年度・令和6年度・令和7年度・令和8年度4月分**。市政概要の「平成28年度分からホームページ上でも公開」は公開開始時期の記述であり、現在の到達範囲とは別（§3-3 で確定）。令和7年度の公開単位は会派分8＋議員分29＝**37単位**。
- **委員会視察は専用ページ「委員会活動（行政視察）」に一覧公表あり**（段階0の「体系的な公表は未確認」を修正）。委員会名・日程・視察都市・内容（テーマ）のみで、参加者・報告書・費用の公表はない。現行ページは令和7年度分（常任6＋特別2＝8件）のみ（§4）。
- **議員の任期**: 定数48・現員47・欠員1。満了日 **2027年4月30日** は市選管「選挙の予定」に公式明記。開始日は前任期満了日からの計算値 **2023年5月1日**（根拠明記が必要、§5）。議長は無所属の長谷川俊英（2026年5月15日選出）で、賛否表では無所属②列に計上され「―」（議決に加わらない）。

### 2-3. 「主な議案」の選定傾向（実物3会期の比較）

選定基準の公式明記は索引ページ・Q&A（市議会に関する質問）・市議会のあらましを探しても確認できなかった。実物の傾向:

- **常に載る**: 当初予算（第2回: 議案第2〜10号）、決算認定（第4回: 第91〜99号）、基本計画等の重要計画（第2回: 第52号 堺市基本計画2030の策定）、副市長等の主要人事（第2回: 第58号 副市長の選任）。
- **載ることがある**: 一部の条例改正（第2回: 第12・15・16・30・54号、第3回: 第73号 学校職員の給与条例）、財産の売払い（第3回: 第67号）。
- **載らない**: 契約の締結・変更、物品の買入れ、市道路線の認定・廃止、人事同意の大半、報告、諮問、意見書・決議の大半（議員提出議案は第15号の条例のみ掲載。意見書4件は不掲載）。
- 分かれた議案だけが載るわけではない（第15号は全会派○でも掲載）。**掲載の有無は議案の性質による議会局の選定であり、賛否の有無とは独立**。登録設計では「賛否一覧に載らない＝賛否は公表されていない」と扱い、全会一致の推定をしないこと（旭川の「全会一致」明記とは異なる）。

### 2-4. 賛否一覧に載らない議案の登録

- 案件（proposals）としては議決等案件一覧に基づき全42件を登録し、結果は一覧の印字どおりとする。
- faction_votes は賛否一覧に載る10件分のみ登録する。載らない案件については faction_votes を作らず、**賛否が公表されていないこと自体** を案件側・証拠パケットに記録する（#9 の設計判断「公表されていないことは復元・推測しない」）。
- votes（議員個人別）は全案件で作らない（公表なし）。電子採決システム導入後も個人別結果の Web 公表は確認できていない（未確認事項2）。

### 3-1. 制度の公式説明

- 条例: 「堺市議会政務活動費の交付に関する条例」。交付対象は **会派（1人会派を含む）又は議員**、議員1人当たり **月額300,000円**。
  - https://www.city.sakai.lg.jp/shigikai/seimuchosa/seimukatsudouhi/kanrenkitei.files/0405jourei.pdf
- 提出: 翌年5月10日までに収支報告書・会計帳簿の写し・領収書等の写しを議長へ提出（第7条）。保存5年（第9条）。閲覧期間は提出期限から60日経過後〜3年を経過する日まで。
- 概要ページ: https://www.city.sakai.lg.jp/shigikai/seimuchosa/seimukatsudouhi/chosahi.html

### 3-2. Web 公表の内容と単位

- 専用索引「インターネット公開」: https://www.city.sakai.lg.jp/shigikai/seimuchosa/seimukatsudouhi/internetopen/index.html
  - 明記: 「令和5年度から令和8年度4月分までの堺市議会政務活動費の収支報告書、事業実施報告書、会計帳簿、領収書等支払証拠書類を公開しています」

  - **収支報告書等**（ファイル名 `..._s.pdf`）: 収支報告書・事業実施報告書・会計帳簿を収録（例: 令和7年度・大阪維新の会分 6,894KB）
  - **領収書等支払証拠書類**（ファイル名 `..._r.pdf`）: 領収書スキャン（同 23,631KB 級）

  - 公明・共産・日本保守党・非所属クラブには議員分の掲載がない（会派分のみ）。交付形態の選択が会派ごとに異なるため、**単位の列挙は各年度の索引ページを正本とする**こと。
- 令和5年度も同形式（会派分5＋議員分30＝35単位。会派構成は当時分）。令和8年度4月分は任期・年度替わりの単月分として別建てで公開されている。

### 3-3. 遡及範囲の確定

- 市政概要資料の「平成28年度分からホームページ上でも公開」は、**Web 公開を開始した時期** の記述である。
- 現在の索引で到達できるのは令和5年度分以降であり、これは条例の閲覧期間（提出期限＋60日〜3年）の建付けと概ね整合する（令和5年度分は2024年5月に提出期限、閲覧は2027年頃まで）。
- 結論: **登録対象は現行索引で到達可能な令和5〜7年度分（＋令和8年度4月分）** とする。平成28年度〜令和4年度分は現在 Web では到達できない（市政情報センターでの閲覧対象期間も過ぎている分がある）。公開期間の制約上、古い年度から順に索引から消えるため、**登録作業の最初に全年度分の収支報告書等 PDF を取得・保存すること**（札幌市議会の政活費保全と同じ扱い。令和5年度分が最も消去が近い）。

### 3-4. 登録への含意

- 登録単位は公式公開の単位に一致させる（#9 の設計判断）: **単位（会派分／議員分）×年度** で、収支報告書等 PDF（_s.pdf）に印字された交付額・支出額（使途項目別内訳を含む）・返納額等を登録する。
- 対象年度は、まず最新の確定年度 **令和7年度（37単位）** を登録し、令和5・6年度は同形式で公表済みのため拡張可能な状態として記録する。
- 領収書等 PDF（_r.pdf）は数十 MB 級のスキャンであり、登録の根拠は収支報告書等で足りる。領収書自体を登録対象にはしない（旭川・豊田の前例どおり）。disclosure profile には、領収書まで Web 公開されている制度事実を記録する。

## 6. 請願・陳情の結果公表

### 6-1. 制度（公式「請願・陳情のご案内」）

- https://www.city.sakai.lg.jp/shigikai/seiganchinjo/seigan.html （更新日 2026年11月17日）
- **請願は本会議と委員会で審議、陳情は関係する委員会でのみ審議** される（堺市の制度上の区別）。審議結果は提出者に通知され、採択した請願は市長に送付される。

### 6-2. 第4回定例会の実物

- 議案書ページ（令和8年第3回から第4回）: https://www.city.sakai.lg.jp/shigikai/kaigi/giansyo/R8-3giannsyo.html
  - 第4回分には **陳情書綴（26,637KB）・陳情回答綴（887KB）** がある。**請願書綴はない**。
- **陳情回答綴**（「陳情第42号〜第60号／令和8年第4回 市議会委員会審査分」）: 陳情 **19件** について、番号・件名・審査委員会・審査日と、項ごとの **審査結果（委員会・所管局の回答文）** を収録する。
  - 陳情番号は **暦年（令和8年）の通し番号**（第42〜60号）。
  - 例: 陳情第42号「行政にかかる諸問題について」審査委員会は議会運営委員会、審査日 9月18日。
  - 注意: ここでの「審査結果」は回答文であり、**採択・不採択の語彙による結論表示ではない**。陳情は本会議の議決対象にならないため、案件一覧（§1）にも現れない。
- **請願**: 第4回では綴・一覧のいずれにも現れない。提出がなかったのか、結論が次回以降なのかは本棚卸しでは確定できない（未確認事項5）。年間の「議決事項一覧」（例: 令和7年中、https://www.city.sakai.lg.jp/shigikai/koho/gikai_hakkoshiryo/R7giketujikouitiran.html ）には「8. 請願」のセクションがあり、年単位では請願の処理結果が集約公表される。令和8年分は2027年3月頃の公表見込みで、事後確認が可能。

### 6-3. 登録への含意

- 陳情19件は、議決案件とは別系統の **委員会審査案件** として登録する。記録する事実は「番号・件名・審査委員会・審査日・審査結果（回答）が陳情回答綴で公表されていること」までとし、採択・不採択の語彙は使わない（公表の単位を超えた解釈をしない）。
- 請願は第4回分としては登録しない（存在が確認できないものを登録しない）。年間議決事項一覧で令和8年分の請願処理が公表された時点で、#706 の更新サイクルにより追加確認する。

### 7-3. 政務活動費（political_activity_expenses / disclosure_profiles）
