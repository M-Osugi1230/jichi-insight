## 0. 本棚卸しの要点（先に読むべき点）

- **大阪府知事・大阪市長の「直近の選挙」は 2023 年の統一地方選挙ではなく、2026年2月8日執行の出直し選挙である**（衆院選と同日）。ただし両者とも任期は 2023 年開始の期が継続し、**満了日は 2027年4月8日**で変わらないことが公式資料で日単位まで確認できる。登録設計では「選挙の回」と「任期の期」を分けて扱う必要がある（詳細は 1-1、2-1、4 節）。
- **堺市長の選挙公報は Web 公式公表がない**ため、公約は term のみの登録になる見込み（豊田市・旭川市と同型）。市長選挙は単独日程（2023年6月4日執行）で、任期満了日 2027年6月8日は市選管の公式公表で裏取りできる（3-1）。
- **3議会とも会派別賛否の公式公表があり**、faction_votes の登録が可能な粒度である（北海道議会の「賛否の公表なし」とは対照的）。議員個人別の公表はいずれの議会にもない。ただし公表の粒度は議会ごとに異なる（府=議決結果 PDF に全案件併記、市=HTML 一覧で全案件×全会派、堺=「主な議案」限定）。
- 政務活動費は 3 自治体とも Web 公開が進んでおり、領収書まで公開されている（北海道の「集計のみ・現地閲覧のみ」とは対照的）。

> **本調査で最も注意すべき点**: 大阪府知事については、調査日（2026-11-20）時点で「直近の知事選挙」は **2026年2月8日執行の出直し選挙** であり、2023年4月9日の任期満了選挙ではない。ただし再選後も任期の満了日は **2027年4月8日のまま変わらない** ことが府選管の公式一覧で確認できる（下記 1-1）。登録設計では「選挙の回」と「任期の期」を分けて扱う必要がある。

### 1-3. 計画・予算資料

- 最上位計画に相当するもの: **「副首都ビジョン」**（大阪府・大阪市の共同ビジョン。伝統的な「総合計画」の名称の計画は現行では置かれていない）

- 副首都・大阪が果たすべき **4つの役割**: 「西日本の首都（分都）」「首都機能のバックアップ（重都）」「アジアの主要都市」「民都」。

### 2-3. 計画・予算資料

- 最上位の将来像: **「大阪市基本構想」**
- 位置付け: 「大阪がめざすべき将来像を明らかにし、大阪市政の方向を定めるにあたっての基本的な考え方」であり、市民等が共有する目標として策定されたもの。札幌市の「まちづくり戦略ビジョン」や北海道総合計画のような **計画期間（目標年次）を持つ総合計画の形式ではない**（基本構想ページに期間・年度の定めはなく、3つの都市像を掲げる理念型の文書）。
- 3つの都市像: ①アジア交流圏の拠点として都市の活気にあふれる大阪、②人が集まり、育ち、新しいものを生み出す大阪、③暮らしたい、訪れたい、魅力あふれる大阪。
- 公式ページ: https://www.city.osaka.lg.jp/seisakukikakushitsu/page/0000005082.html
- ※ 基本構想の **策定年は公式ページ本文に明記がなく未確認**（ページ更新日は 2026-06-30。探した場所: 基本構想ページ全文）。旧「大阪市基本計画 2006-2015」は基本構想の下位計画だったが既に期間終了しており、現行の「基本計画」に相当する期間型の総合計画は本調査では **確認できなかった**。大阪市の計画体系は「基本構想（理念）＋分野別計画＋下記の総合戦略・市政運営方針」で動いていると整理するのが実態に近い。
- 実質的な最上位の政策体系: **「大阪市未来都市創生総合戦略」**（令和6年3月策定、令和7年3月改訂）
- 位置付け: まち・ひと・しごと創生法に基づく国の「デジタル田園都市国家構想総合戦略」を受けた市の総合戦略。「大阪市が将来にわたって持続可能な都市として成長・発展していくため、政策目標や施策の基本的方向、具体的な施策を取りまとめるもの」。市長をトップとする「大阪市未来都市創生会議」で進捗管理を行う。
- 対象期間: **令和6年度（2024年度）～令和10年度（2028年度）の5年間**。
- 構成: （基本目標・数値目標・施策の柱立て・具体的な施策）と（施策ごとの KPI と5年間の工程表）で構成。
- 本編 PDF: https://www.city.osaka.lg.jp/seisakukikakushitsu/cmsfiles/contents/0000650/650566/honpen_R7.3.pdf
- 概要版 PDF: https://www.city.osaka.lg.jp/seisakukikakushitsu/cmsfiles/contents/0000650/650566/gaiyouban_R7.3_lo.pdf
- 体系（本調査で本編を直接集計）:
- **4つの基本目標**: ①未来を担う人材を育成するとともに誰もが活躍できる社会をつくる、②健康で安心して暮らし続けられる地域をつくる、③魅力と活力あふれる大阪をつくる、④DXの推進を通じてそれぞれの幸せを実感できる都市への成長・発展につなげる。
- **数値目標（本編の基本目標 KPI）は計18指標**: ①に6（保育所等利用保留児童数、重大な児童虐待件数、全国学力調査の平均正答率の対全国比、教員の勤務時間基準を満たす割合、若者の就業率、女性の就業率）、②に4（健康寿命、地域包括支援センターの事業評価指標全項目充足割合、街頭犯罪等認知件数、市民活動ポータルサイト情報発信件数）、③に6（実質成長率、日本人延べ宿泊者数、来阪外国人旅行者数、東京圏への転出超過人口、スタートアップ創出数、市域の温室効果ガス排出量）、④に2（行政情報化推進状況の順位・指数、行政手続きのオンライン化数）。

## 4. 設計への影響（段階1以降、北海道・愛知との相違点）

1. **首長 term の設計（最大の相違点）**: 府知事・大阪市長は 2026年2月8日の出直し選挙が直近選挙だが、任期は 2023 年開始の期が継続し、満了日は 2027年4月8日（府は府公式 FAQ と府選管の任期満了一覧で開始・満了とも日単位明記。市は市公式「歴代市長」ページが現任期の開始日 2026年2月9日と1期目の期間を明記し、市選管ページが満了日 2027年4月8日を明記）。北海道型の「日単位の明記がなく計算根拠を証拠パケットに残す」問題は府・市にはない。代わりに、出直し選挙を「新しい任期の開始」と誤って登録しないよう、executive term では選挙（当選回数）と任期の期を分けて記録する設計が必要になる。府公式プロフィールの略歴が「第二期」までの記載で 2026 年再選を期数として明記していない点も、期数の扱いを証拠パケットに明示すべき理由になる。
2. **段階3（公約）の原典の選択**: 府・市とも出直し選挙（2026年）の選挙公報が公式ページから到達可能だが、候補者欄は画像のみでテキスト層がなく、転記には OCR／目視照合が前提になる（北海道知事・札幌市長の画像 PDF と同型）。現任期の起点は 2023 年の選挙であるため、公約レジストリの原典を 2023 年の公報とするか出直し選の公報とするかは段階3で判断が必要（両方とも公式に到達可能であることは本棚卸しで確認済み）。得票数は府・市とも公式開票結果が現存し確認可能。
3. **堺市長は term のみの見込み**: 選挙公報の Web 公式公表がなく、公約原文の安定した一次ソースが特定できなかった（豊田市・旭川市と同型の `no_stable_primary_source_found` 扱い）。任期は満了日 2027年6月8日が市選管「選挙の予定」で裏取りでき、開始日は前任期満了日（2023年6月8日、市選管会議録で公式確認）＋公職選挙法第259条ただし書の構成で確定させる必要がある。選挙が単独日程（2023年6月4日）である点も統一地方選型の他自治体と異なる。
4. **議会の賛否は 3 議会とも会派別登録が可能**: 北海道議会（賛否の公表自体なし）とは対照的に、府議会・大阪市会・堺市議会はいずれも会派別賛否を公式公表している。粒度は議会ごとに異なるため、登録設計は個別に決める: 府議会は議決結果 PDF に全議案・請願・意見書案の会派別態度（●／×）を併記、市会は「議決等案件事項一覧」（HTML）で全案件について全10会派の賛否を公表（全会一致案件も各会派「賛成」と明記される）、堺市議会は「主な議案に対する会派等の賛否一覧」が対象で**「主な議案」以外の議案には賛否公表がない**ため、対象外議案の扱い（賛否なしとして登録）を設計に明記する必要がある。議員個人別の賛否はいずれも公表なし → not_published として登録する。
5. **政務活動費は Web 公開の粒度が高い**: 府は 2015年7月30日から領収書を含む全提出書類を専用ポータルで Web 公開（検索フォーム形式のため一括取得には工夫が要る）、市は令和3〜7年度分の収支報告書・領収書の写しを会派別 PDF で公表、堺は会派・議員個人の両単位で収支報告書から領収書まで Web 公開（現行索引で到達できるのは令和5年度分以降で、遡及範囲は未確認）。交付単位は 3 自治体とも会派＋議員個人の二層であり、登録単位は各自治体の交付・公表単位に合わせる。北海道の「集計＋閲覧制度のみ」の設計は使えない。
6. **計画体系の型が 3 自治体でばらばら**: 府・市には期間型の総合計画が現行では置かれていない。府の最上位相当は府市共同の「副首都ビジョン」（2023年3月改定版）で、事業の母集団は毎年度の「府政運営の基本方針」の知事重点事業一覧が候補。全庁一律の政策評価調書の公表は未確認で、府の重点事業は公式評価なしの登録になる可能性がある。市は理念型の「大阪市基本構想」と「大阪市未来都市創生総合戦略」（2024〜2028年度、4基本目標・数値目標18指標）が実質的な体系で、母集団はアクションプラン編の施策 KPI または当初予算事業一覧が候補。堺のみ「堺市基本計画2030」（2026年3月策定・議会議決済み、27施策・KGI 3・KPI 29）が計画駆動型で、事務事業評価シートが計画の施策・KPI と紐付いて公表されており、北海道型（計画体系＋評価）に最も近い。
7. **財政の受け皿と確定値**: 3 自治体とも FY2026 当初予算は成立後の額を公式資料で確認できる（府: 一般会計 3兆9,216億円、2026年3月24日に原案可決。市: 2兆1,882億円（2,188,221百万円）、2026年3月27日に附帯決議付きで原案可決。堺: 521,700,000千円、2026年3月26日に可決——修正の有無は公式表記が「可決」のみで未確認）。決算の公式資料の所在は自治体ごとに異なり、府は会計局の決算書一式と府債 IR 資料が普通会計の受け皿（府自身の「財政状況資料集」ページは未確認）、市は財政状況資料集（令和元〜6年度分、PDF/Excel）、堺は財政状況資料集が **Excel 形式** で公表され、普通会計決算は監査委員の決算審査意見書でも確認できる。府の令和8年度予算は千円単位の議案総額が未確認で、段階1で議案本文での確認が必要。
8. **段階4の対象会期が自治体ごとにずれる**: 府は令和8年9月定例会（2026年9月17日〜10月20日、知事提出議案35件＋報告13件）、市は令和8年5・6月市会（2026年5月15日〜6月11日。9〜12月市会は調査時点で開会中）、堺は令和8年第4回定例会（2026年8月17日〜9月25日、決算認定を含む市長提出議案27件）が、それぞれ直近の閉会済み定例会になる。
9. **Web 取得**: 3 自治体ともプログラムからの直接接続に遮断は確認されなかった（愛知県公式サイトのような直接接続の切断はない）。実務上の障害は取得可否ではなく形式: 府・市の選挙公報は画像のみ（OCR 必須）、府の政活費ポータルは検索フォーム形式、堺の索引ページはリンクのみで本文が薄い、会議録は 3 自治体とも外部の会議録検索システム側にある。
