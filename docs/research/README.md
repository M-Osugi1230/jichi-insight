# 調査資料アーカイブ（docs/research）

このディレクトリは、Jichi Insight のデータ登録の根拠となった調査資料・監査記録・設計文書のアーカイブです。もともと所有者のローカル環境にのみ存在したものを、共同開発のために 2026年11月19日にリポジトリへ移しました。

登録データの正本は `data/` 配下であり、本アーカイブは「なぜその値・設計になったか」をたどるための背景資料です。内容が現在の登録データと食い違う場合は、一次資料で再確認してください（調査時点の記録であり、その後の補完調査で結論が更新されている場合があります）。
