## 2. 賛否の公表形式（確定）

### 議員個人別（横浜の最大の特徴）

- **議員個人別の賛否が本会議の日ごとに PDF で公式公表される**。対象会期分は3ファイルとも所在を確認した：
  - 9月7日：`kaihabetsu.files/r8_3t_0907sanpi.pdf`（1件のみ）
  - 9月9日：`kaihabetsu.files/r8_3t_0909sanpi.pdf`（1件のみ）
  - 9月25日：`kaihabetsu.files/r8_3t_0925sanpi.pdf`（2ページ、34件）
- 表の構造：案件ごとに「番号・件名・**結果**・**委員会報告**」＋議員全員分の列（会派順に配列）。記号の凡例が各 PDF に明記されている：
  - **•：賛成、×：反対、空欄：投票なし、除：除斥、／：欠席（退席）**
  - 「議長は採決には加わりません」と注記（定数86名に対し採決対象は85名。議第10号の賛成15・反対70＝85名と整合）
- **記号の意味づけ（重要）**：注記によれば記号は「委員会報告に対する賛否」として表示される（委員会報告欄に結果の記載がある場合、委員会報告に賛成＝•、反対＝×）。結果欄には最終結果（原案可決・採択・不採択等）が別に印字される。通常の議案では両者は実質同義だが、**請願では委員会報告の勧告（採択／不採択）への賛否が記号になる**ため、請願第7号（結果：不採択）では多数派が •（不採択の委員会報告に賛成）となっている。登録時はこの二層構造を証拠パケットに明記し、請願の賛否の解釈を取り違えないこと。
- 議員提出議案（議第7〜11号）は委員会付託が省略されるため委員会報告欄は「―」で、記号は議案自体への賛否。
- 登録可能な議員別レコード規模：表決36件 × 85名 ＝ **最大3,060件**（欠席・除斥・投票なしを含む。座標レベルの照合が必須 — テキスト抽出では氏名と記号の対応が崩れる）。
- 会派の配列（賛否表の表頭、17区分）：自由民主党、公明党、立憲民主党、日本維新の会、国民民主党、日本共産党、地域政党よこはま、自民無所属連合、無所属、および1人会派を議員名で表示（井上さくら、市民の党、斉藤達也、輿石かつ子、横浜の風、田中ゆき、長谷川えつこ、大野トモイ）。正式な会派名・所属は登録時に議員名簿で確定すること（政活費の報告書では「日本維新の会横浜市会議員団・無所属の会」という名称が使われており、賛否表の「維」と同一かは名簿で確認が必要）。

### 会派別

- 「議案に対する各会派の賛否一覧」PDF が会期ごとに公表される形式で、市会だよりにも会派別の賛否表が掲載される（段階0で確認）。ただし**第3回定例会分の会派別一覧 PDF の直接 URL は本棚卸しでは特定できなかった**（未確認事項）。

## 3. 政務活動費

### 制度（段階0＋本棚卸しで確認）

- 交付額：**月額55万円（議員1人あたり年6,600,000円）**。交付先は会派または議員個人（報告書様式第5号は両形式に対応）。
- 収支報告書は翌年度4月30日までに議長へ提出。様式は収入（交付額）、支出（**11項目**：調査研究費、研修費、広報費、広聴費、要請・陳情活動費、会議費、資料作成費、資料購入費、人件費、事務所費、事務費。各項目に金額と備考）、合計、差引きを印字する。
- **検算可能性：あり**。項目別金額の合計＝支出合計、収入−支出合計＝差引き、の検算が全単位で可能。ただし様式の注意書きに「『２　支出』における合計金額の記載は、政務活動費の交付金額の範囲内となります」とあり、**実支出が交付額を超える単位では印字上の合計は交付額で頭打ちになり差引き0円となる**。登録値は印字どおりとし、この様式上の性質を証拠パケットに記録すること。

### Web 公表の実態（実物で確定）

- 入口：「政務活動費 収支報告書等の公開」https://www.city.yokohama.lg.jp/shikai/koho/seimukatsudouhi/seimu_koukai.html ／年度別一覧「各年度の収支報告書」https://www.city.yokohama.lg.jp/shikai/koho/seimukatsudouhi/kakunendhoukokusho/index.html
- 公表範囲：**令和5年度（2023年5月〜2024年3月交付分）以降**。ファイルは年度別ディレクトリ（`kakunendhoukokusho/reiwa6.files/`、`reiwa7.files/` 等）に報告書 PDF が単位ごとに置かれる。
- 公表単位は**公表ファイルの単位そのまま**で、年度内に混在する：
  - 会派単位の年次報告（例：令和6年度 公明党横浜市会議員団 収入99,000,000円＝15名分、自由民主党横浜市会議員団）
  - 議員個人単位の年次報告（例：令和6年度 輿石かつ子 6,600,000円、太田正孝 6,600,000円、いそべ尚哉 6,600,000円。1人会派の地域政党よこはま・横浜の風も個人と同額の単位で公表）
  - **令和7年度分では議員個人分に四半期単位のファイルが存在する**（例：高橋のりみ 令和7年度4〜6月分、収入1,650,000円＝55万円×3か月、ファイル名 `R7takahashi_R7.4-6.pdf`、報告日2025年7月18日）。個人分の期間分割が全員に及ぶかは登録時に年度別一覧で全件列挙して確定すること。
- 登録設計：登録単位は**各年度の公表ファイル単位**（会派×年度／議員×年度／議員×四半期）。範囲は Web 公表のある令和5年度（5月〜3月）・令和6年度・令和7年度交付分。登録前に各年度のファイル一覧を全件列挙し、単位の総数を確定させること。
- **領収書等の写し：Web 公開なし**。横浜市会図書室（市会議事堂3階）で閲覧のみ（原則、交付年度の翌年度7月30日ごろから、提出期限の翌日から5年間。複写は市政刊行物・グッズ販売コーナーで有料）。disclosure profile に「収支報告書は Web 公開、領収書は図書室閲覧のみ」と制度として記録する。根拠：公開ページおよび横浜市会政務活動費の交付に関する条例施行規程第10条（段階0記録）。

## 9. 取得上の注意・登録時の注意

- 賛否表 PDF はテキスト抽出では氏名と記号の対応が崩壊する。**座標レベルの照合**で議員と記号を対応づけること（先行クラスターの名古屋・札幌・大阪府と同型）。
- 議案番号は**年度通し番号**であり、当会期は市第20号から始まる。第2回定例会分（市第1〜19号・議第1〜6号・請願第1〜6号）と混同しないこと。
- 決算の番号は4系統（決算市・決算水・決算交・決算病）＋利益処分は通常番号（市第45号・水第2・3号）という混在形式。番号の写し間違いに注意。
- 新市長（原澤敦美）の就任は対象会期の閉会後（2026-10-18）であり、**対象会期の議案はすべて前市長・山中竹春の在職中または市長不在期間に提出されたもの**である。議第10・11号（パワーハラスメント関連決議）や市第44号（前市長の退職手当特例）はこの経緯と一体の案件として、結果文言・提出日を正確に記録すること。
- 政活費の報告書は年度途中で宛先の議長名が変わる（令和6年度分は鈴木太郎議長宛、令和7年度分は渋谷健議長宛）。単位の同定は宛先ではなく会派名・議員名と対象年度で行うこと。
- 政活費の支出合計は様式上、交付額の範囲内に丸められる（§3）。「差引き0円」は実支出が交付額以下だったことを必ずしも意味しない。
