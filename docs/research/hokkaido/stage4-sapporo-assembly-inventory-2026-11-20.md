## 2. 賛否公表の粒度

### 2-1. 会派別賛否: 公表あり（2系統の一次資料で照合可能）

- **系統1: さっぽろ市議会だより「本定例会の議決結果一覧」**
  - 各定例会号の1ページに、議案等ごとに **各会派の賛否（賛成＝●／反対＝×）** と結果を表形式で掲載。凡例（会派略称）付き。
  - No.151（令和8年第2回定例会分）の列構成: 自民・民主・公明・共産・坂元・かずさ・未来・健康・大地・市民ネ・維新の11会派列。
  - 行は議案グループ単位にまとめられる（例: 「議1・2・4・5）令和8年度札幌市補正予算」）。名古屋と同様、**グループ行を個別議案へ展開する処理が必要**。
  - 報告（報）は全会派「－」（採決対象外）。
  - 号のページから面別 PDF へリンクする形式で、賛否表は「本定例会の議決結果一覧」の面（No.151 では2ページ）: https://www.city.sapporo.jp/gikai/html/shigikaidayori-151.html
- **系統2: 議決事件等一覧表（PDF）の反対会派略号**
  - 本会議結果欄に反対した会派を略号で付記する（例: 「可決（共反対）」「可決（坂反対）」）。反対会派がない案件には付記なし。
  - 加えて、提出者・付託委員会・委員会審査日と委員会結果（「可決すべきものと決定」等）・本会議議決日が議案ごとに載るため、**議案番号と賛否の対応付けはこの表自体で完結する**（名古屋で必要だった会議録による番号照合は札幌では不要）。
  - 会派略称の公式対応表は「本会議の結果」ページ末尾に掲載（2026年11月13日現在）: 自＝自由民主党、民＝民主市民連合、公＝公明党、共＝日本共産党、坂＝坂元・荒井、かずさ＝山口かずさ、未来＝未来さっぽろ、健康＝健康さっぽろ、大地＝大地さっぽろ、市民ネ＝市民ネットワーク北海道、グリ＝グリッド札幌（2026年11月13日〜）、維新＝日本維新の会。
- 2系統は相互に照合できる（第2回定例会では「共反対」4件・「坂反対」1件がだより表の × と一致した）。登録時は両方を証拠パケットに収める設計が可能。

### 2-2. 議員個人別: 公表なし（not_published）

- だより賛否表は会派別のみ、議決事件等一覧表は反対会派の略号のみ、議案等一覧（HTML）は結果のみ。
- 本会議の採決は起立採決で、会議録（速報版）には「賛成者起立」「起立多数」等と記録されるのみで、個々の議員名は記録されない（段階0で確認）。記名投票による議員個人別の賛否表が掲載された公式ページは特定できなかった。
- → 議員個人別投票は「公表なし（not_published）」として扱い、復元・推測はしない（#9 の設計判断どおり）。

### 2-3. 注意点（賛否表の読み取り）

- **「かずさ」列は No.151 の賛否表で全行「－」だった**。山口かずさ議員（1人会派）が当該会期の採決に参加しなかったのか、1人会派の表記仕様なのかは **未確認**。登録時に議決事件等一覧表・会議録で裏取りが必要（欠席等の事実を推測で登録しない）。
- 陳情の行の「×」は「不採択とすることへの賛成（＝陳情の採択に反対）」を意味する。●/× の意味論は「案件の原案（陳情では採択）に対する賛否」で統一されており、結果欄の「不採択」と併せて解釈する必要がある（3 章）。
- だより賛否表・議決事件等一覧表とも、**テキスト抽出では行と記号・数値の対応が崩れる**（実際に抽出結果で確認）。登録時は座標レベルの照合が必須。

## 3. 請願・陳情の扱い

- 制度（公式の案内ページで確認）:
  - 請願: https://www.city.sapporo.jp/gikai/html/seigan.html ／ 陳情: https://www.city.sapporo.jp/gikai/html/chinjo.html
  - いずれも受理後に原則として関係委員会へ付託され、委員会が「採択すべきもの」「不採択とすべきもの」の決定をしたものは**本会議で「採択」または「不採択」を議決**する。結果は提出者へ通知される。
  - 陳情取扱要綱（令和6年6月20日制定、令和8年4月1日一部改正）により、委員会付託に適さない陳情（法令違反・公序良俗違反を求めるもの、議決済みの請願・陳情と同一趣旨のもの等）は付託されず全議員への情報提供にとどまる場合がある。
- **会期単位の結果公表は存在する**（福岡市と同型）:
  - 本会議で議決された請願・陳情は、**議案等一覧（HTML）に結果つきで掲載**される（第2回定例会の陳情90件＝不採択の実例を確認）。
  - **議決事件等一覧表には請願・陳情が個別に全件掲載**される。受理年月日・付託委員会・委員会審査と結果・本会議議決日・結果まで載り、集計欄にも請願件数・陳情件数が明示される（第2回定例会: 請願0件・陳情90件。参考: 令和6年第3回定例会は請願0件・陳情0件）。
  - 陳情の委員会結果欄には、委員会内の反対者（会派名・議員名）が付記される場合がある（例: 「不採択とすべきものと決定（自民、共、公、坂、未来、健康丸岡議員、大地脇元議員、市ネ米倉議員、維新波田議員反対）」）。これは委員会採決の記録であり、本会議の会派別賛否とは別レイヤーとして扱うこと。
- 登録単位の線引き:
  - 登録対象は**本会議で議決された請願・陳情**に限る。委員会で継続審査中のもの（例: 陳情第393号「札幌市都心部の喫煙対策に関する陳情」は令和8年6月3日初審査→10月6日継続審査中）や付託されなかったものは、会期の結果公表に現れないため登録対象外とし、継続中の事実は委員会の活動状況ページで追跡できる旨を記録するに留める。
  - 陳情90件のような同一趣旨の一括案件は、議決事件等一覧表では**個別90件**、議案等一覧（HTML）とだより賛否表では**1件に集約**して公表される。登録は一覧表の個別行を正本とし、集約公表との対応（番号範囲）を証拠パケットに明記する設計が適切。会派別賛否は集約行の値（全会派×）を90件共通の値として扱えるが、その旨の注記が必須。
  - 請願は対象2会期とも0件だったが、制度上は陳情と同一の公表経路を持つため、将来の会期で発生した場合は同じ設計で登録できる。

## 4. 政務活動費

### 4-1. 制度と公表形式

- 交付単位: **会派のみ**（議員個人への交付なし）。根拠: 札幌市議会政務活動費の交付に関する条例（平成13年条例第8号）第2条。交付額は月額40万円×会派所属議員数（第3条、4・7・10・1月に3か月分ずつ交付）。年度により減額の附則あり（令和2年7月〜令和3年3月は月額36万円、令和3年7月は24万円、同年8月〜令和4年3月は36万円）。
- 収支報告書・政務活動概要報告書: **会派単位で Web 公表（PDF 直接リンク）**。政務活動費ページに年度別・会派別に両報告書の PDF を掲載する。
  - 政務活動費ページ（2026年7月30日更新）: https://www.city.sapporo.jp/gikai/html/seimukatsudouhi.html
  - 掲載範囲: **令和2年度交付分〜令和7年度交付分**（本調査で全年度分の掲載を確認）。会派×年度の数は年度で異なる: 令和7年度12会派・令和6年度10会派・令和5年度9会派・令和4年度6会派・令和3年度5会派・令和2年度5会派（合計47会派年度）。
  - PDF の URL は年度ごとに命名規則が異なり規則性が弱い（例: 令和7年度自民の収支報告書 = `documents/01_jimin-2026-1.pdf`、令和2年度自民の収支報告書 = `documents/jimin2020-1-1.pdf`）。登録時は政務活動費ページから各リンクを辿って取得することが前提になる。
- 会派構成の変動が激しい（例: 日本維新の会札幌議員会は令和7年7月31日解散し、健康さっぽろ・日本維新の会が同年8月1日結成。令和5・6年度にも改称・再編の注記あり）。報告書の会派名は各年度の表記のまま登録し、取得日と注記を記録すること。

### 4-2. 公開期間と取得の緊急度（最重要）

- **公開期間: 収支報告書等（収支報告書・政務活動概要報告書・領収書等）は「公開開始日から5年間」公開**（政務活動費ページの明記）。
- 閲覧開始の起算: 閲覧等に関する要綱（令和7年3月18日改正）第3条により、閲覧は「収支報告書等を提出すべき期間の末日の翌日から起算して90日を経過する日の翌日」から可能になる。実務上、各年度分は例年7月下旬に政務活動費ページへ掲載されている（ページ更新日は2026年7月30日で、令和7年度分の掲載と対応）。
- **令和2年度分（最古）の公開終了時期**: 令和2年度分の公開開始は2021年7月下旬〜8月頃と推定され（年度別の正確な公開開始日は公式ページに明記がなく **未確認**）、5年を経過する2026年7月下旬〜8月頃が本来の終了時期になる。**ただし2026年11月20日現在も令和2年度分はページに掲載中であることを本調査で確認した**。運用上は年次更新（翌年度分の掲載）時に古い年度分が外れる差し替え方式と見られ、**令和2年度分の取得期限は実質的に次回年次更新（2027年7月頃、令和8年度分の掲載時）まで**と判断する。
- **緊急度: 高**。取得の優先順位は 令和2年度分（5会派×2文書）→ 令和3年度分 → それ以降の順。名古屋（公開1年・期限2027年7月上旬）とほぼ同じ時期に期限が来るため、段階4の登録作業では政活費 PDF の取得・保存を最初に行うべきである。
- なお、Web 公表が終わった年度分も議会図書室（市役所本庁舎15階）での閲覧は可能とされるが、Jichi の登録作業の原典としては Web 取得が前提になる。

### 4-3. 領収書等の写し

## 7. 抽出上の注意点

1. **議案番号は会期ごとに振り直される**（年度通算ではない）。令和8年第2回・第3回とも議案第1号から始まる。登録キーは「会期＋系列＋番号」で設計する必要がある。系列は議案・諮問・意見書案・決議案・報告・請願・陳情がそれぞれ独立。
2. **賛否表と一覧表は座標照合が前提**。だより賛否表（●/× のグリッド）と議決事件等一覧表（縦書き混じりの大表）は、テキスト抽出では行・記号・日付の対応が崩れる。名古屋の PDF 賛否表と同じ扱い（一覧表は HTML 版がないため、PDF の座標読みが正本作業になる）。
3. **だより賛否表のグループ行の展開**。「議1・2・4・5」のような複数議案のグループ行を個別議案へ展開する際は、グループ定義（対象議案の番号と件名の対応）を議案等一覧・議決事件等一覧表で必ず突合すること。
4. **陳情の賛否の意味論**。だより表の × は「不採択への賛成」。faction_votes への変換では「採択に対する賛否」として正規化し、結果（不採択）と混同しないこと。
5. **会派の新設・改称・解散が頻繁**。会派名と略称は会期時点のものを使う。略称の公式対応表は「本会議の結果」ページに現在分のみが載るため、過去会期分は当該会期のだより凡例を正本にする。
6. **政務活動費 PDF の URL は年度ごとに命名が異なる**。リンク切れ・差し替えに備え、取得時にファイル自体を保存し、出典 URL と取得日を記録すること（公開期間5年の制約と併せて、取得＝保存が前提）。
7. **議案等一覧（HTML）の陳情は集約表示**。90件が1行にまとめられ、番号範囲もだより表と議案等一覧で表記がずれる場合がある（議案等一覧は「第253号〜第359号」、だより表は内訳を列挙し一部番号が欠ける）。個別番号の確定は議決事件等一覧表の個別行で行うこと。

## 8. 要点（段階4の登録設計への含意）

- **対象会期の推奨**: 令和8年第2回定例会（会期2026年5月21日〜6月5日、議決121件＋報告13件）。議案・結果は議案等一覧（HTML）と議決事件等一覧表（PDF）、会派別賛否はだより No.151 賛否表と一覧表の反対略号の2系統照合で登録できる。令和8年第3回定例会（決算会期）は議決事件等一覧表と No.152 の公表後に追加する。
- **議員別登録は不可能**: 会派別が公表の上限。議員個人別は not_published として記録する。
- **請願・陳情は登録可能な公表単位がある**: 本会議議決分は議案等一覧と議決事件等一覧表に結果つきで載る。陳情の一括案件（90件）は個別行を正本に登録する。継続審査中・未付託のものは対象外。
- **政務活動費は取得が時間制約付き**: 会派×年度（令和2〜7年度・47会派年度）の収支報告書が登録上限。**令和2年度分は次回年次更新（2027年7月頃）で Web から消える見込みのため、登録作業の最初に全年度分の PDF を取得・保存すること**。領収書は申請閲覧（流布禁止）のため登録対象外。
- **委員会視察は公表単位あり**: 委員会×年度の報告書 PDF。常任6委員会のうち4委員会と調査特別委員会2つで掲載を確認。範囲は令和5〜8年度を基本とする。
- **任期**: 満了 2027年5月1日は道選管の公式一覧で確定。開始 2023年5月2日は法構成による整理として根拠を明記する。
- **最大の難所**: (a) だより賛否表・議決事件等一覧表の座標レベルの読み取り、(b) 賛否表のグループ行の個別議案への展開、(c) 政務活動費 PDF の取得期限（2027年7月頃）、(d) 「かずさ」列が全行「－」である理由の裏取り。
