## 2. 賛否公表の粒度（段階0の結論を一次資料で再確認・確定）

**結論: 会派別・議員個人別のいずれも公式公表なし（確定）。** 登録できるのは「議案×議決結果」までであり、faction_votes / member votes は公表されていないこと自体を登録する。

再確認の根拠（本調査で直接見た資料）:

1. **議案処理簿**: 議案ごとに議決状況（原案可決・同意議決・継続審査 等）を示すのみで、賛否数・会派別態度の欄は存在しない。
2. **本会議会議録（速報版・全8日分を通読検索）**: 起立採決は「起立多数であります」という議長の宣告のみで、**起立者数・議員名は記録されない**。簡易採決は「御異議なしと認めます」のみ。反対討論者名（丸山はるみ・真下紀子）は記録されるが、これは討論の記録であり賛否の公表ではない（討論者以外の反対者の有無・人数は会議録からも分からない）。
3. **議事日程（各日本会議ページ）**: 採決方法（起立／簡易）の別は示されるが、結果は件名単位の議決結果のみ。
4. **議案等カテゴリ全体**: 会議案・決議案・意見案・請願・動議の各一覧にも賛否・態度の情報はない（愛知県議会の「議案等に対する各会派の態度」PDF に相当する公表物は存在しない）。
5. **議会広報カテゴリ**: 「道議会トピックス」等の広報物のみで、会期ごとの賛否表を載せる議会だより類は存在しない（段階0で道の広報誌「ほっかいどう」の道議会レポートにも賛否がないことを確認済み）。
6. 探した場所の全体: 議会公式サイトの会期ページ群・議案等カテゴリ（d005）・会議録等カテゴリ（d006）・議会広報カテゴリ（d007）・サイトマップ・委員会ページ群・会議録（速報）全8日分。なお「北海道議会時報」の賛否表の有無は未走査（§10）。

採決方法の登録について: 起立採決か簡易採決かは議事日程・会議録から議案グループ単位で判別できる（起立採決は議案第1号・第4号と意見案第1号・第6号のみ）。登録時に method として記録することは可能だが、グループ単位の採決（複数議案の一括採決）が常態である点に注意。

## 4. 政務活動費

### 4-1. 制度（公式ページ・条例で確認）

- 根拠条例: 「北海道議会の会派及び議員の政務活動費に関する条例」。交付対象は **会派と議員個人の両方**（愛知・福岡と同様の二層構造）。
- 会派: **月額10万円 × 所属議員数**
- 議員: **月額43万円**
- 報告義務: 会派・議員とも、年度終了日の翌日から原則30日以内に、収支報告書と **すべての支出の領収書等の写し** を議長へ提出。議長の調査は学識経験者3名の「北海道議会政務活動費調査等協議会」（平成22年設置）が補佐。

### 4-2. Web 公表の範囲: 集計のみ（確定）

## 5. 委員会視察・議員派遣

### 5-1. 委員会の道内・道外調査: 報告書の公表なし（確定）

- 各常任・特別委員会のページ（審議概要）は HTML の議事一覧のみで構成され、「道内調査実施報告の件［委員長報告］」「道外調査実施報告の件［委員長報告］」といった **委員長報告が行われた事実** は記録されるが、報告書本文・調査先・日程・参加者・費用を記した文書は添付・一覧化されていない。
- 本調査で確認した委員会: 総務委員会、総合政策委員会、経済委員会、文教委員会、建設委員会、北方領土対策特別委員会、子ども政策調査特別委員会、食と観光調査特別委員会（いずれも第32期後期のページ）。全て同形式。
- 委員会会議録は会議録データベースに登載される（平成24年以降の常任委員会等）が、委員長報告の内容は会議録本文中の口頭報告であり、「視察報告書」の公表物ではない。福岡・愛知の前例で登録した inspection_trips（公式の一覧・報告書に基づく記録）に相当する公表物は北海道議会には存在しない。
- 結論: **委員会視察は「報告書・一覧の公式公表なし」を欠損として登録** する（not_published）。審議概要に現れる「調査実施報告の件」の存在は、視察の実施自体の傍証として証拠パケットに記録するに留め、個別の視察レコードは作らない（公表単位が存在しないため）。

## 7. 抽出上の注意点（登録作業の難所）

1. **議案処理簿 PDF の文字化け**: テキスト層はあるが、一部の字形が化ける（例: 議案第24号の件名「財産」が抽出時に欠落字となった）。件名の登録は処理簿の平文抽出を鵜呑みにせず、必要に応じて PDF 実物の目視または条例案 PDF・種類別一覧と突合すること。
2. **fs 配下 URL のパーセントエンコーディング**: 日本語ファイル名の URL は1バイトでも欠けると 404 になる（本調査でも再タイプで欠落し 404 を踏んだ）。出典 URL はページ HTML の href からそのまま転記すること。
3. **提出案件一覧ページはリンク集にすぎない**: HTML 表は存在しない。確定情報は処理簿 PDF（知事提出分＋議員提出分を1ファイルに収録）と、種類別一覧（会議案・決議案・意見案は期通し一覧のため、対象会期分は処理簿で切り分ける）。
4. **会議録の二層構造**: 速報版（インターネット版）は正式会議録とは一部異なり訂正されうる旨が公式に注記されている。第3回定例会の正式版は調査時点で未登載。賛否・請願の確認に速報版を用いたことは証拠パケットに明記し、正式版登載後に差異があれば更新する。
5. **一括採決が常態**: 採決は議案グループ単位（例: 議案第2号・第3号・第5〜18号・第20〜28号・諮問第1・2号を一括で簡易採決）。method を登録する場合はグループ単位の記録になる。
6. **継続審査の状態管理**: 議案第19号・報告第1〜6号（決算）は「上程済み・未確定」であり、欠落ではない。結論（認定・不認定 等）が出た会期で状態を更新する設計が必要（愛知の決算の扱いと同型）。決算の結論は令和8年第4回定例会以降に出る見込み。
7. **政活費の比較表の表頭**: 公式ページの前年度比較表はテキスト抽出で年度ラベルの対応が崩れやすい。令和7年度の本表は単独表で明確だが、令和6年度値は比較表の視覚的な列順で確認すること。
8. **請願一覧の更新ラグ**: ページ更新日が会期より古い場合がある（§3-2）。登録直前に再取得し、対象会期の区分が追加されていないか確認すること。
9. **議員数の変動**: 欠員・逝去・補欠選挙で会派別議員数は変動する。出典には必ず「現在日」を併記する。
