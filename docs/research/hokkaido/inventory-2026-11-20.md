### 1-3. 計画・予算資料

- 最上位計画: **「北海道総合計画」**（2024年7月策定）
  - 位置付け: 北海道行政基本条例に基づく、道が策定する計画のうち最も基本となる計画。長期的な展望に立って道の政策の基本的な方向を総合的に示す。特定分野別計画・地域計画は総合計画に沿って策定される。
  - 対象期間: **2024（令和6）年度から概ね10年間**（概ね10年後の2030年代半ばの「めざす姿」を展望）。
  - めざす姿: 「北海道の力が日本そして世界を変えていく」「一人ひとりが豊かで安心して住み続けられる地域を創る」
  - 公式ページ（本編・概要版・簡易版・英語版の PDF／デジタルブック、指標個票へのリンク）: https://www.pref.hokkaido.lg.jp/ss/sks/hokkaido_sogokeikaku.html
- 計画体系の柱（重点事業の母集団候補）:
  - **3つの政策展開の基本方向** と **18の政策の柱**、政策の方向性ごとに **108の指標**（重複を含め113）を設定。
    - 基本方向1 潜在力発揮による成長: （1）食、（2）観光、（3）ゼロカーボン、（4）デジタル、（5）ものづくり・成長分野、（6）産業活性化・業種横断分野
    - 基本方向2 誰もが可能性を発揮できる社会と安全・安心なくらし: （1）子ども・子育て、（2）教育・学び、（3）医療・福祉、（4）就業・就労環境、（5）中小企業・商業、（6）安全・安心
    - 基本方向3 各地域の持続的な発展: （1）地域づくり、（2）グローバル化、（3）北海道の強靱化、（4）社会経済の基盤整備、（5）自然・環境、（6）歴史・文化・スポーツ
  - この18柱の下に施策が整理されており、後述の政策評価の施策体系と一致する。事業（プロジェクト）登録の母集団としては、総合計画の施策体系＋当初予算の「重点政策」が候補になる（愛知クラスターの「主要政策／実施計画」に相当する独立した実施計画文書があるかは未確認。下記参照）。
- 進捗・評価の公表形式: **政策評価（基本評価）として公式公表あり（HTML 一覧＋施策別調書）**
  - 根拠法令: 北海道政策評価条例。総合計画の政策体系に沿って整理した **施策ごと** に「基本評価調書」を作成し、PDCA の段階ごとに順次公表する（Plan＝目標・課題等 → Do&Check＝取組実績・評価 → Action＝評価を踏まえた対応）。
  - 総合判定は4段階: 「順調」「概ね順調」「やや遅れている」「遅れている」（Do&Check 時点で公表）。
  - 令和7年度基本評価調書ページでは、18の政策の柱の下に施策コード（4桁、部局番号＋連番）付きで全施策の総合判定と調書リンクが一覧公表されている（例: 0601 農業農村整備の推進＝概ね順調）。公表履歴: Plan 2025年7月28日、Do&Check 2025年11月26日、Action 2026年7月2日。
  - 出典: https://www.pref.hokkaido.lg.jp/ss/sks/ksk/sesakuhyoka/228449.html
  - 総合計画指標・施策の進捗状況を分野別にまとめた資料（基本方向ごとの指標進捗と施策評価結果、PowerPoint 由来 PDF）も道公式サイトで公表されている。例（基本方向3分）: https://www.pref.hokkaido.lg.jp/fs/1/3/2/3/8/3/9/0/_/%E7%B7%8F%E5%90%88%E8%A8%88%E7%94%BB%20%E6%8C%87%E6%A8%99%E3%83%BB%E6%96%BD%E7%AD%96%E3%81%AE%E9%80%B2%E6%8D%97%E7%8A%B6%E6%B3%81(%E5%9F%BA%E6%9C%AC%E6%96%B9%E5%90%913).pdf

## 5. 要点（議会データの深掘り可否）と段階1以降への注意点

- **会派別・個人別賛否**: 3自治体で粒度が大きく異なる。
  - 北海道議会: **会派別・議員個人別のいずれも公式公表なし**。議案ごとの議決結果（原案可決等）のみ。採決は簡易採決・起立採決が中心で、会議録には反対討論者名は残るが賛否の公表とは扱わない。faction_votes は原則登録不可で、登録できるのは「議案×議決結果」まで。
  - 札幌市議会: **会派別のみ公表**（市議会だより PDF の議案ごと会派別 ●/× 表＋議決事件等一覧 PDF の反対会派略号）。議員個人別は公表なし（起立採決で会議録にも個人名は残らない）→ 個人別は not_published として扱う。
  - 旭川市議会: **議員個人別あり（条件付き）**。全会一致の議案は「全会一致」とのみ記し、賛否が分かれた議案だけ別ページで議員個人別の賛否（賛成・反対・欠席・採決に加わらず）を HTML 表で公表。本会議の議決における個人別賛否として登録可能で、会派別集計は個人別から導出できる。
- **政務活動費の公開単位**:
  - 北海道議会: 交付は会派＋議員個人の両方だが、**Web 公開は集計（交付額・支出額・返納額・執行率）のみ**。収支報告書・領収書は議会庁舎閲覧室で5年分を現地閲覧する方式で、Web では取得できない。深掘りでは集計値と閲覧制度の登録にとどまる（愛知・福岡の登録済み事例より公開が薄い）。
  - 札幌市議会: 会派単位のみ交付・公表。収支報告書・政務活動概要報告書は会派別 PDF を直接 Web 公表（令和2〜7年度交付分を確認）。領収書等の写しは全件添付で、議会図書室閲覧＋令和6年度分からインターネット公開（ただし専用ページからの閲覧申請形式で、機械的な一括取得には適さない可能性）。**公開期間は公開開始日から5年間**の制限あり。
  - 旭川市議会: 交付は会派＋無所属議員。決算書（写し）は過去5年分を HP 公表、会計帳簿・領収書等の証拠書類（写し）は平成29年度執行分から HP 公表、報告書は平成31/令和元年度分から HP 公表。公表単位は会派別＋無所属議員個人別。3自治体で最も Web 公開が進んでいる。
- **選挙公報**: 北海道知事選・札幌市長選は公式掲載ページから PDF に到達可能（公約原文ソースとして利用可能）。**旭川市長選（2025）は Web 公式公表に到達できず**、豊田市と同様に「公約原文の安定した一次ソースなし」の扱いになる見込み。
- **委員会視察**: 札幌市（委員会単位の行政視察結果報告書 PDF）と旭川市（委員会別の概要 HTML＋委員個人別報告書 PDF）は公表あり。北海道議会は報告書本文の公表が未確認（審議概要に議事記録のみ、議員派遣報告書は旧サイトに平成29年分が残存）。
- **首長の任期の日単位**: 3自治体とも公式ページでの日単位の直接明記が弱い。北海道知事は前任期満了日（2023-04-22、道内自治体の公式公表で確認）＋公職選挙法259条の計算、札幌市長は総務省・北海道選管等の公式任期満了日一覧、旭川市長は選管への直接確認または当選証書・告示等の公式文書で、それぞれ裏取りしてから登録する必要がある。
- **計画・重点事業の母集団**:
  - 北海道: 「北海道総合計画」（2024年7月策定、概ね10年間）の18の政策の柱＋108指標の施策体系が政策評価（基本評価調書、4段階の総合判定を一覧公表）と一致しており、施策体系＋当初予算の重点政策が母集団候補。愛知の「主要政策／実施計画」に相当する独立した実施計画文書は未確認。
  - 札幌市: 最上位は「第2次札幌市まちづくり戦略ビジョン」（2022〜2031年度）。事業レベルの母集団は中期実施計画「アクションプラン2023」（2023〜2027年度、599事業・1兆7,854億円）で、進捗報告 PDF と行政評価（全施策・全予算事業の自己評価調書公表＋外部評価）がある。
  - 旭川市: 「第8次旭川市総合計画」（2016〜2027年度・12年、基本目標5・基本政策13・施策34・成果指標41）。推進計画の展開施策／重点事業が母集団候補。点検報告書 PDF あり。行政評価シートは個別 PDF が散在し一覧索引は未確認のため、推進計画＋点検報告書を主軸とするのが安全。
- **財政の注意点**: 札幌市の当初予算は財政局ページが「当初予算案」表記のまま更新される形式のため、成立後の額の確定には議案等一覧の可決記録との2点セットで根拠を取る必要がある。旭川市は予算の概要ページ（HTML＋予算書 PDF）で成立後の額が議決と対応付けて確認可能。北海道は議案第1号の総額と「財政状況」第157号（成立後扱い）の額が一致し、成立後の額が公式に確認できる。
