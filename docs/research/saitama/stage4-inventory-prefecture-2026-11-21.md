## 2. 賛否公表の粒度（実物で確定）

**結論: 会派別（8会派）の賛否と、無所属議員3名の個人名列が、知事提出議案35件と議員提出議案16件の全件について公式公表されている（確定）。ただし決算認定2件（第116・117号）は継続審査のため賛否欄が空欄（表決なし）。会派所属議員の個人別公表はなし。**

### 2-1. 記号体系と表の構造

- 表決状況 PDF の凡例: **○：賛成　×：反対（賛成でない）　除：除斥　欠：欠席**。議決結果の区分は「原案可決」「可決」「同意」「承認」「否決」「継続審査」「審議未了」等と凡例に明記される。
- 本会期で実際に使われた記号は ○ と × のみ（除・欠 の出現なし。テキスト抽出で全件確認）。
- 列構成: **8会派＋無所属議員3名の個人名列**。議員数は表の注2どおり「表決状況確認時の人数」で、自民50・民主フォーラム11・公明9・県民5・共産党3・改革1・さくらの会1・ネット1＝81名、無所属3名で合計84名となり、議員名簿（2026年9月24日掲載、現員84人）の構成と一致する。
- 登録可能な賛否: 賛否欄がある49件 × 8会派 ＝ **会派別賛否 392件**、49件 × 無所属3名 ＝ **個人別賛否 147件**（無所属議員分のみ）。
- **賛否が分かれたのは7件**: 共産党が反対 6件（第104・106・108・109号、議第51・52号）、さくらの会と無所属・諸井議員が反対 1件（議第53号 ICC意見書）。残り42件は全会派・無所属全員が賛成。

### 2-2. 決算認定2件の賛否欄

- 第116・117号は議決結果「継続審査」のみが印字され、**会派別・個人別の賛否欄は空欄**（継続審査の決定自体は委員会付託と同日の10月7日）。賛否を補完・推測して登録してはならない。登録は結果（継続審査＝pending）のみとし、賛否は欠損として扱う。

### 2-3. 懲罰・請願の賛否

- 懲罰2件は表決状況 PDF の対象外で、懲罰ページにも賛否の記載はない → 賛否は公表なしとして登録する（結果「可決」のみ）。
- 請願（採択1件）への会派別態度の公表もない。

## 4. 請願・陳情

- **請願**: 本会議で議決（採択／不採択）。9月定例会の請願ページには「1件を採択しました」と明記され、採択された請願の全文（件名・請願事項・請願理由）が掲載されている:
  - 「県教育委員会および県立学校における重大事態対応体制の検証と改善に関する請願」（採択）
  - **請願番号はページに公表されていない**（番号欄なし）。登録は件名ベースとなる。
  - 不採択・継続審査となった請願の有無・件名は公式ページでは確認できない（請願ページは採択分の掲載形式）→ 欠損として記録する（§9 未確認事項2）。
- **陳情**: 県議会の案内（請願・陳情のご案内）によれば、受理された陳情は「陳情一覧表を全議員に配布し、陳情書の写しを各会派に配布」する扱いで、**委員会審査・本会議での結論（了承／不了承）を出す制度ではない**。したがって陳情は登録対象の結論を持たない（制度自体を disclosure profile に記録する）。

## 5. 政務活動費

### 5-1. 制度と公開範囲

- 交付は **会派単位**（議員1人当たり月額50万円を所属議員数で交付）。
- Web 公開: **令和2年度交付分から**、会派ごとに収支報告書（当初提出分と訂正分）と、使途項目別（調査研究費・グループ活動費・広聴費・要請陳情等活動費・広報費・人件費・事務所費・事務費・資料購入作成費・交通費）に分割された領収書等の写しを公開。公開期間は提出日の翌日から5年間。各年度の閲覧ページが f1603/seimukatsudouhi/ 配下にある（令和2〜7年度分を確認）。
- 登録対象年度は先行クラスターの慣例どおり **令和7年度分**（最新の確定年度）とする。

### 5-2. 令和7年度分の登録単位（実物で確定）

令和7年度分は **11単位**（全て会派単位）:

- 自民党議員団（閲覧ページ -1 系。収支報告書は documents/286062 配下）
- 埼玉民主フォーラム／公明党県議団／無所属県民会議／日本共産党埼玉県議会議員団／無所属改革の会／無所属の会／保守無所属の会／青藍会／周山会／埼玉県市民ネットワーク（閲覧ページ -2 系。documents/286074 配下）

- 収支報告書の様式: 収入（政務活動費の額）、支出（10分類の科目別金額と合計）、残余が印字される。
- **検算可能性: 高い**。本棚卸しで2単位を実測:
  - 埼玉県市民ネットワーク: 収入 2,000,000円、支出内訳（調査研究費4,000＋広報費230,083＋事務費201,647＋資料購入作成費4,900＋他0）＝ **合計 440,630円**（印字の合計と一致）、残余 **1,559,370円**（収入−支出と一致）。
  - 自民党議員団: 収入（政務活動費）329,500,000円、**支出合計 339,364,779円、残余 0円**。支出が交付額を上回る単位があり、残余は0円と印字されている。登録は印字値どおりとし補正しない（§8 注意点4）。

### 5-3. 年度による単位構成の差異

- 令和7年度の交付単位には、令和8年9月定例会時点の表決状況の会派にはない **無所属の会・保守無所属の会・青藍会・周山会** が含まれ、逆に **さくらの会（無所属保守さくらの会）は令和7年度の交付単位にない**。会派の結成・名称変更が年度間にあるため、政活費の単位名は各年度の報告書の印字どおりに登録し、現行会派名への読み替えをしない。

### 5-4. 訂正版の扱い

- 一部の会派では、当初提出分（令和8年4月30日収受）に加えて **訂正分（令和8年11月10日収受）の収支報告書** が公開されている（埼玉民主フォーラム・日本共産党埼玉県議会議員団で確認）。登録時は訂正分を正本とし、当初分との差異を証拠パケットに残すこと。

## 6. 視察・議員派遣

### 6-1. 議員派遣（本会議議決分）

- §1-2 の議第54・55号の2件が本会期の議員派遣（いずれも原案可決、会派別賛否つき）。派遣先・目的は議案一覧の要旨で確認できるが、**派遣議員の人数・氏名は要旨に記載がない**。

### 6-2. 委員会視察（閉会中の委員会活動）

- **集約した専用一覧ページは確認できない**（段階0の未確認事項9は「専用一覧なし」で確定）。常任委員会・特別委員会の視察は、議会事務局発行の **議会記録 PDF 内「閉会中の委員会活動」** に委員会単位で掲載される。
- 様式（実物確認: 令和7年度分、総務県民生活委員会の例）: 委員会ごとに「調査日・調査先・調査の概要（調査目的・視察先の概要と特色・質疑応答）」が記載される。常任委員会6・特別委員会6が対象。
- **参加委員の氏名一覧と費用（旅費等）の記載は、確認したサンプルでは見当たらなかった**（§9 未確認事項3）。登録する場合は委員会・日程・視察先の単位に留める設計になる。
- 議員派遣（§6-1）とは別制度であり、混同しないこと。

### 6-3. 政務活動費による海外視察の報告書

- 政務活動費の令和7年度ページ末尾に「視察報告書」として **海外視察報告書2件** が掲載されている: 埼玉県議会日台友好議員連盟台湾視察報告書、台湾視察報告（青藍会・周山会）。議員連盟・会派が政務活動費で行った視察の報告書であり、委員会視察（§6-2）とは別系統。登録範囲に含めるかは登録時の設計判断とする（本棚卸しでは存在と所在を確定させた）。

## 8. 登録時の注意点（確定事項）

1. **結果文言は表決状況 PDF を正とする**: 議案一覧 HTML の「審査結果」欄は、人事案件（彩の国功労賞・教育委員会委員の任命）でも一律「原案可決」と表示されるが、表決状況 PDF では「同意」と区分される。表決状況 PDF の凡例が議決結果の区分を定義しているため、登録の結果文言は PDF の印字どおり（同意21件）とする。議案一覧は件名・要旨・提出日の原典として使う。
2. **表決状況は議会運営委員会で確認した態度**: 表決状況 PDF の注1に「各会派議員の議案に係る賛否については、採決を行う本会議に先立って開かれる議会運営委員会で確認しています。この表は、議会運営委員会で確認した内容を議案ごとに示したものです」と明記される。愛知県議会と同じ性質であり、この注記を登録（証拠パケット・disclosure）に落とさないこと。無所属議員3名の列も同じ確認に基づく個人名列である。
3. **決算認定2件は賛否欄が空欄**: 継続審査のため表決自体が行われていない。賛否を補完しない。結果は pending（継続審査）として登録し、結論の更新は #706 の対象。
4. **政活費は印字値どおり**: 支出が交付額を上回る単位（自民: 支出 339,364,779円 ＞ 交付額 329,500,000円、残余 0円）がある。残余は印字どおり0円で登録し、収入−支出で再計算して置き換えない。訂正分がある会派は訂正分を正本とする。
5. **会派名は資料ごとの印字どおり**: 表決状況（略称＋凡例の正式名称）、政活費（各年度の報告書の会派名）、議員名簿で表記が異なる。年度をまたぐ対応付け・読み替えはしない（§5-3）。
6. **懲罰・請願は賛否なしで登録**: 懲罰2件と請願1件は表決状況 PDF の対象外で、賛否の公式公表がない。結果のみを登録し、賛否は not_published とする。
7. **第115号（次期5か年計画）は継続審査中**: 計画の登録（段階2）は現行計画を正本として完了済みであり、第115号の結論（策定の可否）が出るまでは次期計画を登録しない。結論が出たら #706 の手順で計画レビューの差し替えを行う。
