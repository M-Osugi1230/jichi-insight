### 良好だった点（実測）

- 全ページで lang / title / description / viewport が揃い、h1 は1件、見出しの飛びは皆無。
- 画像は全ページで `<img>` 0件（アイコン等はテキスト/CSS で構成）。alt 欠落の問題は存在しない。
- 宮城県ページの検索フォームは input / select とも `<label for>` で関連付け済み。チップ切替は `<button aria-pressed>` を使用。
- グラフは画像や canvas ではなく、aria-label「年度実績の推移」を付けた `<ol>`（テキストの時系列）で表現されており、支援技術でも内容が読める設計。
- 外部リンク（宮城県 142件等）は全件 rel="noreferrer" 付きで、テキストに「PDF ○ページ ↗」と形式・ページ数・外部遷移が明示されている。
- ナビゲーションには aria-label（「主要ナビゲーション」「モバイルナビゲーション」等）が付与されている。
- CSS に :focus-visible ルールが5件あり、outline の一律無効化（outline:none）は0件。
- 本文のコントラストは良好（推定）: 本文色 #10202e は背景 #fffefa に対して 16.41:1、補足色 #42505b は 7.48:1（いずれも CSS 変数からの推定計算）。
