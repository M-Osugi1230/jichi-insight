# 愛知クラスター 段階3・豊田市: 太田稔彦氏の公約原典の棚卸し結果

調査日: 2026-11-19
対象: 令和6年2月4日執行の豊田市長選挙（太田稔彦氏が4選）における、太田氏の候補者としての公式公表物
目的: Issue #722（段階3・公約登録）の原典として検証可能な形で使える資料が存在するかの確定。前提調査 `../cluster2-stage3-toyota-gazette/findings.md`（選挙公報の公式 Web 版は現存しないことが確定済み）を踏まえた続編。

---

## 結論

**太田稔彦氏の2024年市長選挙における公約の原典として、検証可能な形で現存する候補者公式公表物は特定できなかった。**

したがって、北九州市・武内和久の前例（候補者公式サイトの政策PDFの Wayback 保存版を原典とする）に倣える原典は存在せず、**豊田市長の公約は「原典が特定できないため未登録」とする**のが妥当である。公約文を報道の要約や候補者アンケートの回答から推測・再構成して登録することはしない。

## 探した場所と結果

### 1. 候補者本人の公式ウェブサイト — 存在を確認できず

- Wikipedia「太田稔彦」の外部リンクは、Facebook ページ（太田稔彦豊田市長、ユーザー名 mayor.toyota.city）と Instagram（@ota_toshihiko_toyota_mayor）、市の「市長の部屋」のみで、個人公式サイトへのリンクはない。
- 想定ドメイン（ota-toshihiko.jp / toshihiko-ota.jp / ota-toshihiko.com / ota-toshihiko.net / oota-toshihiko.jp / toyota-ota.jp / mayor-ota.jp / t-ota.jp / toyota-city.jp）の Wayback Machine 保存は全て無し（availability API で確認）。
- 検索エンジンで「太田稔彦 公式サイト」「後援会 ホームページ」等を複数クエリ確認したが、本人の公式サイトはヒットしない。後援組織「21世紀の豊かなまちをつくる会」のウェブサイトも特定できなかった。
- 選挙戦自体が、地元紙に「陣営は市議選に関わったことがあるぐらいの素人の集まり」と評される体制で、事務所開設も告示4日前（2024-01-24）だったことが報じられており、Web での体系的な公約公表が行われなかった可能性と整合する（これは状況証拠であり、不存在の断定根拠にはしない）。

### 2. Facebook ページ — 選挙期間中の保存なし

- 本人の Facebook ページ（mayor.toyota.city）の Wayback 保存は、2024-02-01 時点で最も近いものが2020-11-05 の保存であり、2024年選挙期間中の保存はない。Facebook の保存コピーは投稿本文の検証にも適さない。

### 3. 選挙ドットコム（go2senkyo） — 豊田市長選の記事・公報コピーなし

- 福岡市前例（候補者HPの公約全文を引用した記事の保存コピー）と同種の記事を探すため、Wayback に保存された go2senkyo.com/articles/2024/ の2024年1〜2月分12件を全件確認した。内訳は前橋市長選・京都市長選の記事と選挙ドットコムちゃんねるまとめ等であり、**豊田市長選挙の記事はなかった**（同日投開票の前橋・京都には記事がある）。
- 選挙公報 PDF のコピー（prod-cdn.go2senkyo.com/public/senkyo_koho/）については、検索エンジンで該当なし。Wayback CDX のプレフィックス全件照会はタイムアウト（504）で完遂できなかったため、CDN 上の全件不存在までは断定しない（未確定事項に残す）。なお前提調査でも選挙ドットコム等の民間ミラーは「検索で該当なし」とされている。

### 4. 国立国会図書館 WARP — 該当を確認できず

- WARP の検索（太田稔彦）では該当ページを確認できなかった（検索応答がエラー画面へ遷移し、収集サイト一覧からの直接確認は行っていない）。Wayback で結論が確定した前提調査と合わせ、深追いはしていない（未確定事項）。

### 5. 報道の候補者アンケート・政策比較 — 存在するが原典として扱わない

- 中日新聞が両候補に子育て・防災・名鉄豊田市駅前再開発の3テーマを聞いた記事（2024-01-31 等）など、候補者の回答・主張を伝える報道は存在する。
- しかしこれらは新聞社の質問への回答・報道側の要約であり、候補者自身の公式公表物（公式サイト・選挙特設ページ・マニフェスト公表物）ではない。福岡市前例が第三者記事を原典にできたのは「候補者ホームページの公約全文の原文引用」だったためであり、本件とは来歴が異なる。したがって原典としては採用しない。

### 6. 選挙公報（公式 Web 版） — 現存しない（前提調査で確定済み）

- `../cluster2-stage3-toyota-gazette/findings.md` のとおり。市は選挙期間中の Web 掲載を予告していたが、選挙ページ一式は投開票直後に削除され、公報ページ・PDF のアーカイブ保存もない。紙公報の現物確認（選管保管・図書館所蔵）は Web 調査の範囲外。

## 未確定事項

- go2senkyo の選挙公報 CDN（prod-cdn.go2senkyo.com/public/senkyo_koho/）の全件確認は Wayback CDX のタイムアウトで完遂できていない。検索エンジン・記事アーカイブの両面で該当がないため、存在する可能性は低いと判断するが、不存在の完全な証明ではない。
- WARP の収集有無は検索経路の問題で確定できていない。
- 紙の選挙公報・法定ビラ等の現物は未確認（オフライン経路が必要）。

## 段階3への含意

- 豊田市長・太田稔彦の公約レジストリ登録は行わない（原典が特定できないため未登録）。これは「公約が存在しない」ことの主張ではなく、「検証可能な原典を特定できなかった」という記録である。
- 首長の term 自体の事実関係は段階0棚卸しで公式資料により確認済み（太田稔彦、選挙日 2024-02-04、任期 2024-02-19 〜 2028-02-18、愛知県公式「市町村長等名簿」・「任期満了日等一覧表」による）。term レコードの登録は本作業の分岐指示（原典なしの場合は PR を作らない）により本作業では行わず、別途の判断に委ねる。
- 将来、紙公報の現物や go2senkyo CDN のコピーが特定できた場合は、その時点で原典として登録し直す余地がある。
