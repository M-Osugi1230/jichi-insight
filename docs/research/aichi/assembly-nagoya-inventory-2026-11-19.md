## 2. 賛否公表の粒度

### 2-1. 市会だより（公式広報紙）の賛否表 — HTML版が議員別登録の正本になる

- 市会だよりは PDF 版と HTML 版の両形式で公式公表される。各号に概要ページがあり、記事別の HTML ページと面別 PDF（＋全ページ PDF）へのリンクを持つ。
  - 最新: 第203号（令和8年11月号、8月定例会特集）概要: https://www.city.nagoya.jp/shikai/kouhou/1030998/1054718/1054719/index.html
  - 第202号（令和8年9月号、6月定例会特集）全ページ PDF: https://www.city.nagoya.jp/_res/projects/default_project/_page_/001/052/592/r809all.pdf
- **議員別賛否表は「賛否ページ」として HTML 表でも公表される**（賛否が分かれた議案がある号のみ）。
  - 第202号 賛否ページ: https://www.city.nagoya.jp/shikai/kouhou/1030998/1030999/1051058/1052591/1052592/1052602.html
  - 第198号 賛否ページ: https://www.city.nagoya.jp/shikai/kouhou/1030998/1030999/1034675/1043433/1043412.html
  - 同形式のページは古い号にもある（例: 第192号＝令和6年6月定例会、第162号＝平成30年6月定例会）。
- 表の構造（HTML版）: 行＝議員（全68人）、列＝会派・議員名（選出区）・議案（群）ごとの賛否。値の体系は次の4種:
  - `賛成` / `反対`
  - `採決時に不在`（第198号で実例あり）
  - `議長のため議決に参加できない`（議長は会期ごとに異なる: 令和7年9月定例会では西川学、令和8年6月定例会では小出昭司）
- 対象範囲の限定（重要）:
  - 賛否表に載るのは**賛成多数で可決した市長提出議案のみ**。全会一致の議案は、号の本文に「以下の○件については、全会一致により…」と叙述で列挙されるだけで、議員別の行は作られない（全員賛成は叙述が根拠になる）。
  - 議員提出議案（意見書等）は近年の号では全て全会一致の叙述のみで、賛否表の対象になっていない。
  - 賛否が分かれた議案が複数ある場合、議決日と賛否パターンが共通する議案は（1）（2）…の**グループにまとめられ、列は議案ごとではなくグループごと**になる（第198号: 9件を4列に集約。グループと議案の対応はページ本文に明記される）。
- **会派別集計表は別途公表されていない**。ただし HTML 表の各行に会派が付記され全議員が漏れなく載るため、会派別人数は行の集計で機械的に導出できる（公表単位そのものは議員別）。

### 2-2. PDF版の賛否表（照合用。抽出は座標依存）

- PDF版（2・3面見開き）の賛否表は、横軸に議員を会派順に並べた大きなグリッドで、氏名は姓・名を複数行に割って縦に配置し、セルに ○（賛成）・×（反対）の記号を置く形式。
- テキスト抽出では氏名の行と記号の対応が崩れる（実際に抽出結果で確認）。**PDF から議員別賛否を読む場合は座標レベルの照合が必須**であり、実務上は HTML 版を正本とし、PDF は裏付け照合に使うのが安全。

### 2-3. 市会だより以外の公式の結果公表

- **議案一覧表**（1-1の会期別ページ）: 全議案について議案番号・案件名・提出日・付議委員会・議決日・議決結果（可決/承認/同意/異議なき旨の答申議決/認定 等）を HTML 表で公表。議員別・会派別の賛否は載らない。議決結果の確定値の正本はこちら。
- **定例会の概要（速報版）**: 閉会直後に PDF で公表。議案群ごとの結果（全会一致/賛成多数）を速報するが、議員別賛否は載らない（例: 令和8年6月分 r806.pdf、8月分 https://www.city.nagoya.jp/_res/projects/default_project/_page_/001/054/065/r808.pdf ）。
- 会議録は本会議の審議経過を記録するが、起立採決のため議員別の賛否は記録されない。議員別賛否の公式公表は市会だよりの賛否表が唯一の経路と判断する。

### 2-4. 請願・陳情の扱い

- 名古屋市会の請願は、本会議の議決ではなく**常任委員会の閉会中審査**で結論を出す方式（委員会が「採択すべきもの」「不採択とすべきもの」「審査打切」を決定し、議長が大要を市会公報に記載・議員へ報告、7日以内に議員3人以上の異議がなければ委員会の決定が市会の確定となる）。審査結果は請願人に通知される。
  - 根拠（請願・陳情の案内）: https://www.city.nagoya.jp/shikai/bouchou/1031732.html
- 陳情は、請願に適合するものは委員会に送付され委員長が報告するが、結果は陳情者に通知されない。
- **会期単位の請願・陳情の結果一覧は Web 公表されていない**（市長提出案件・議員提出議案の一覧表にも含まれない）。請願の結果公表単位は市会公報と請願人への通知であり、福岡の前例のような「会期×請願×会派別賛否」の登録単位は名古屋には存在しない。段階4では請願・陳情は登録対象外とするか、公表単位がないこと自体を記録する扱いが適切。

## 5. 抽出上の注意点

1. **議案番号は4つの系列＋議員提出議案で、それぞれ年度通算**。
   - 通常議案（第○号）は年度内で通し番号（令和8年度: 2月定例会 第1号〜 → 6月 第124号〜第137号 → 8月 第138号〜第144号）。
   - 認定案・承認・同意・諮問はそれぞれ独立した通し番号（例: 6月定例会＝承認第5号・同意第6号・諮問第1号、8月定例会＝認定案第1号〜第5号・同意第7号・第8号）。
   - 議員提出議案も年度通算（6月 第8号〜第12号、8月 第13号〜第18号）。会期だけでは番号が一意にならないため、登録キーは「会期＋系列＋番号」で設計する必要がある。
2. **賛否表と議案番号の対応付けが公式公表のどこにもない**。
   - 賛否表は議案を説明文（例: 「契約の一部変更（名古屋城天守閣整備事業先行工事（木材の製材）について、完成予定期日を変更するもの）」）でしか特定しない。一方、議案一覧表の案件名は「契約の一部変更について」とだけあり、同名議案が同一会期に複数ある（令和8年6月定例会では第132号・第133号・第134号がいずれも「契約の一部変更について」で付議委員会が異なる）。
   - 令和8年6月定例会の名古屋城案件は、付議委員会（経済水道委員会）からは第134号と推定できるが、公式公表物同士の直接の対応付けはない。**登録時は会議録（委員会審査の記録）で番号を照合する工程が必要**。
3. **全会一致議案には議員別の行が存在しない**。議員別レコードを作る場合、全会一致分は「市会だよりの叙述による全員賛成（全会一致）」という根拠種別を区別して扱うこと。賛否表があるのは賛成多数の市長提出議案だけであり、会期の全議案に議員別賛否が揃うわけではない。
4. **賛否表の列は議案単位とは限らない**。複数議案が議決日・賛否パターンでグループ化される（第198号の（1）〜（4））。グループから個別議案への展開は、ページ本文のグループ定義（対象議案と議決日の列挙）を必ず併せて読むこと。
5. **PDF の賛否表は座標照合が前提**（2-2参照）。HTML 版がある号は HTML を正本にできる。HTML 版の賛否ページは号ごとに URL 階層が異なり（ページIDも不規則）、概要ページから辿る必要がある。
6. **議長は会期途中で交代しうる**（令和7年9月: 西川学 → 令和8年6月: 小出昭司）。「議長のため議決に参加できない」の帰属は会期ごとに賛否表で確認すること。
7. **認定案は会期をまたぐ**。令和7年度決算は、公営企業分（認定案第1〜5号）が8月定例会で継続審査→11月定例会へ、一般会計等分（認定案第6〜17号）が11月定例会に提出、という分割になっている。決算を軸に登録する場合は会期の切り方に注意。
8. **政務活動費の Web 公開は1年で消える**（3参照）。棚卸し時点（2026-11-19）で取得可能なのは令和7年度分のみで、期限は2027年7月上旬。過去分の遡及登録は Web 経路では不可能。

## 6. 要点（段階4の登録設計への含意）

- **対象会期の推奨**: 令和8年6月定例会（全22件が議決済み・公表完結、議員別賛否表あり）。8月定例会は認定案5件が未確定のため、登録するなら継続審査の明示が前提。決算重視なら令和7年9月定例会が賛否表の厚い代替候補。
- **議員別登録が可能**: 賛否表が HTML 表で公表され、全68議員×賛成多数議案の値（賛成/反対/採決時に不在/議長のため参加不可）が機械可読に近い形で得られる。会派別集計は議員別行からの導出になる。
- **登録単位の線引き**: 議案と議決結果は議案一覧表（会期別 HTML）が正本。議員別賛否は賛成多数の市長提出議案に限られる。請願・陳情は会期単位の公表単位が存在しない。政務活動費は会派×年度（報告書 PDF、1年の取得期限あり）。委員会視察は公表単位なし（議員派遣の海外出張報告は別区分で公表あり）。
- **最大の難所**: (a) 賛否表の議案説明文と議案番号の対応付け（会議録照合が必要）、(b) 賛否表のグループ列を個別議案へ展開する処理、(c) 政務活動費 PDF の取得期限（2027年7月上旬）。
