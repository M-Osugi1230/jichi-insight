# 愛知クラスター 段階3 前提調査: 豊田市長選挙（2024）の選挙公報の Web 公表状況

調査日: 2026-11-19
対象: 令和6年2月4日執行の豊田市長選挙（告示 2024-01-28、任期満了に伴う選挙。太田稔彦 77,107票 対 鈴木雅博 74,796票で太田氏が再選）の選挙公報
目的: 段階3（公約登録）の原典として、選挙公報の公式 Web 公表物が使えるかを確定する。段階0棚卸し（`../cluster2-aichi-inventory/findings.md` 項目 #1）の未確認事項への回答。

---

## 結論

**現在、豊田市長選挙（2024）の選挙公報は、公式の Web 公表物としては存在しない（確定）。**

- 市の公式選挙ページ自体が選挙終了後に削除されており、現行の豊田市公式サイトに当該選挙公報の掲載ページ・PDF はない。
- 選挙期間中については、市公式ページが「選挙公報（1月下旬順次掲載予定）」と明記しており、**期間中の Web 掲載が公式に予告されていた**ことは確認できる。ただし、掲載期間中（2024-01-28〜02-04）のページ・PDF の実物は Wayback Machine にも保存されておらず、実際に掲載されたことの直接証拠は得られなかった（予告文言のみが証拠）。
- したがって、段階3で太田稔彦氏の公約原典として使える「公式 Web 公表の選挙公報」は現存しない。

## 根拠

### 1. 旧公式選挙ページの保存版に「選挙公報（1月下旬順次掲載予定）」の明記がある

- 豊田市長選挙ページ（旧 URL）: https://www.city.toyota.aichi.jp/shisei/senkyo/1056483/index.html
- Wayback Machine 保存版（2024-01-19 時点）: https://web.archive.org/web/20240119101926/https://www.city.toyota.aichi.jp/shisei/senkyo/1056483/
  - 同ページのメニュー項目に「投票できる人」「期日前投票について」等と並んで **「選挙公報（1月下旬順次掲載予定）」** と明記されている（この時点ではリンクなしのテキスト項目で、掲載先ページは未公開だった）。
  - 2023-12-31・2024-01-11 時点の保存版でも同ページの存在を確認。

### 2. 選挙ページは選挙終了直後に削除された

- 同 URL の Wayback 保存: 2024-02-07・2024-02-17 の両時点で **404**。投開票（2月4日）の直後に選挙ページ一式が削除され、公報の掲載先もろとも現行 Web から消えている。

### 3. Wayback に公報ページ・PDF の保存がない

- Wayback CDX で `city.toyota.aichi.jp/shisei/senkyo/` プレフィックスの 2024年1〜4月の保存を全件確認。2024-01-28〜02-29 の保存は以下のみで、公報ページ・PDF の保存はない。
  - 選挙速報ページ https://www.city.toyota.aichi.jp/shisei/senkyo/1057716/index.html （2024-02-02 保存。公報へのリンクなし）
  - 上記 1056483 の 404 保存（2件）
- 1056483 配下の保存は全期間を通して HTML 3 URL のみ（index・投票所ページ）。PDF の保存はない。

### 4. 現行公式サイトに公報の掲載はない

- 現行の選挙セクション（例: 愛知県知事選挙ページ https://www.city.toyota.aichi.jp/shisei/senkyo/1081212/index.html ）は今後の選挙が中心で、2024年市長選の公報への導線はない。
- 検索エンジンで `site:city.toyota.aichi.jp 選挙公報 豊田市長選挙` 等を確認しても、該当する公式ページ・PDF はヒットしない。

### 5. 愛知県選管の公報掲載は市長選を対象としない

- 愛知県選挙管理委員会「投開票の状況・選挙公報」: https://www.pref.aichi.jp/soshiki/senkyo/0000087359.html
  - 掲載対象は衆議院・参議院・知事・県議会議員など県が管理する選挙のみ。市長選挙の公報は掲載されていない（制度上も市選管の発行物）。

## 未確定事項

- **選挙期間中に実際に公報が Web 掲載されたか**: 市の予告文言（「1月下旬順次掲載予定」）は確認できたが、掲載期間中のアーカイブ保存が存在しないため、掲載の実施自体は直接確認できていない。掲載されたとしても選挙終了後に削除済みであり、現在の原典としては使えない点は変わらない。
- **紙の選挙公報の現物**: 選挙公報そのものは規程に基づき発行され世帯配布されたはずだが、選管保管分・図書館所蔵等の現物確認は本調査の範囲外（Web 公表の調査のみ）。
- **国立国会図書館 WARP**: 豊田市サイトの収集保存の有無は、本調査では検索経路を特定できず未確認。Wayback で結論が確定したため深追いしていない。

## 段階3への含意

- 太田稔彦氏の 2024 年公約の原典として、**選挙公報の公式 Web 版は使用不可**。愛知県知事選・名古屋市長選（いずれも公式掲載ページあり）とは扱いが異なる。
- 公報の内容が必要な場合は、選挙管理委員会への公文書開示請求・閲覧、市立図書館等の所蔵確認といったオフライン経路が別途必要。
- 候補者公式サイト等の資料を使う場合は、選挙公報とは別の一次資料として明確に区別して登録すること（公報の代替として混同しない）。
