## 2. 表示要件

1. **公約一覧**（首長・任期ごと）: 柱（policy_area）のまとまりで原文を表示する。statement は原文のまま改変しない。要約が必要な場合は summary フィールドを使い、原文と要約を視覚的に区別する。
2. **進捗状態**: 状態語彙は `lib/statusLabels.ts` の既存ラベルを使う。**not_assessable は「未評価」ではなく「評価材料なし（未接続）」の意味で表示する** — 未着手・未達と誤認される表現（赤色表示、×印、達成率バー）は使わない。
3. **達成度・スコアの表示禁止**: 首長ごとの達成率、件数ベースの進捗率（例: 6/34 進行中）、ランキング、色分けによる優劣表現は一切出さない（Issue #8 の受け入れ条件）。
4. **事業接続の表示**: 公約→事業のリンクには「関連事業（自動推定を含む・要確認）」である旨と確信度を明示する。事業ページ側の逆リンクも同様。接続がない公約は「接続事業なし」と明示する（空白にしない）。
5. **出典の表示**: 各公約に出典へのリンクと格付けを表示する。特に福岡市分は「候補者サイトの直接保存ではなく、同時期の原文引用＋選挙公報照合」である来歴を出典表示で分かるようにする。県分は選挙公報が原典であることを示す。
6. **target の表示**: target がある公約だけ、目標値と（登録がある場合のみ）実績を分離して表示する。目標と実績を同じ系列に混ぜない。

## 3. 是正が必要な既存文案（実データとのずれ）

`/executives` ページの固定文案が現在の登録実態とずれているため、UI 実装時に是正すること:

- 「個別公約への分割や達成度の判定は行っていません」等の文案 → 公約レコードが49件登録済みである実態に合わせる（達成度の判定は行わない点は正しいので、表現は維持しつつ「分割・登録は実施済み」に直す）。
- 「福岡県知事・福岡市長は安定した公約原文資料を未発見」等の文案 → 両者とも原典を確保し登録済みのため削除・更新する。
