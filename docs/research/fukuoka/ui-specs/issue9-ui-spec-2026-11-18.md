# Issue #9 UI 仕様書（議会アカウンタビリティ）— 2026-11-18

対象: 福岡県議会・福岡市議会・北九州市議会。データは段階0〜5（PR #664〜#669）で登録済み。
置き場所: `data/reviewed/<自治体>/assembly/`（assembly_records.json / disclosure_profiles.json /
sessions.json / proposals.json / votes.json / faction_votes.json /
political_activity_expenses.json / inspection_trips.json ＋各証拠パケット）。

## ページ構成

1. **/assemblies（議会一覧）**: 3議会のカード。各カードに自治体名・議会名・任期・定数と、
   「この議会で公開されているもの」のサマリ（DisclosureProfile の項目別 availability を要約）。
   議会どうしのランキング・比較表にはしない（併記まで）。
2. **議会詳細ページ**（/assemblies/<slug> 等、既存ルーティングに合わせる）: 以下のセクション。
   - 基本情報: 任期、定数・現員（欠員があればそのまま表示）、会派構成（会派名と人数）、委員会数。
   - 会期と議案: Session ごとに Proposal 一覧（議案番号・件名・提出者・議決日・結果）。
     予算議案は related_fiscal_record_ids の接続先（自治体の財政ビュー）へリンクする。
   - 表決: Vote / FactionVote の表示（下記制約を厳守）。
   - 政務活動費: FY2025 分。公開単位どおりに表示（下記制約）。
   - 視察: inspection_trips の一覧（目的・日程・参加者・費用・報告書リンク）。
   - 公開状況: DisclosureProfile の全項目を availability / granularity / note のまま表示する
     「この議会の情報公開」セクション。

## 表示制約（厳守）

- **議員別表決**: 3議会とも member_vote_availability = not_published。
  「議員ごとの賛否は公表されていません」と明示する。議員別の賛否を推測・復元した表示は禁止。
- **会派別表決**: 福岡市・北九州市のみ公表あり（FactionVote を会派名・人数とともに表示）。
  福岡県議会は「会派ごとの賛否は公表されていません」と明示する。
  北九州市の position: split は「会派内で賛否が分かれた」と表示する。
  totals が null の議案では人数の合計を表示しない。
- **結果文言**: 県のグループ文言など、登録された文言どおりに表示し、「原案可決」等への
  言い換えをしない。outcome の機械表示と原文言が併記できる場合は原文言を優先する。
- **政務活動費**: 登録単位をそのまま表示する。福岡市は会派分＋議員個人分、県・北九州市は
  会派単位のみである旨を明記する（個人分がないことを欠損として表示）。
  残額が null の2件（県）は「支出が交付額を超過（詳細は出典資料）」と注記し、0や空白で誤魔化さない。
  領収書は「窓口でのみ閲覧可能」と DisclosureProfile どおり表示する。
  **議員・会派の支出額ランキングは作らない**（並びは公式資料の掲載順または名称順）。
- **視察**: 費用は公表されているもののみ表示し、未公表は「費用は公表されていません」と明示する
  （福岡市は全件未公表、県は2件が金額なし）。北九州市は現任期分の視察報告書の公表がない旨を
  表示する（過去分を現任期の実績として表示しない）。
- **議員ページ・活動量指標**: Member には活動量指標が存在しない。質問回数などのランキングや
  議員スコアは表示しない。議員名簿を表示する場合は名簿属性（氏名・会派・選挙区等、登録済みの
  範囲）のみ。
- **帰属の分離**: 議案の成果を議会・議員の実績として表現しない。執行部の事業・成果と混同する
  文案は使わない。
- **出典**: 各セクション・各レコードに証拠パケット／公式出典へのリンクを付ける。
  欠損・未収録は「未収録」「公表されていません」と明示し、空白で誤魔化さない。
