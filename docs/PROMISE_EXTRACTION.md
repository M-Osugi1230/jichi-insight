# Promise extraction and assessment rules

## Purpose

公約資料から記録を作るとき、文章を細かく分けるほど件数は増えます。しかし、件数を増やすための分割は、候補者が約束していない内容を作り出す危険があります。

Jichi Insightは、公約数を増やすことより、原文の境界と評価可能性を守ることを優先します。

## Source hierarchy

1. 選挙管理委員会が公表する選挙公報
2. 候補者本人または公式選挙事務所が公表したマニフェスト
3. 当選後に自治体が公表した政策方針・所信表明
4. 報道記事や第三者の要約

3と4は、選挙時の公約原文の代替として扱いません。補足資料または実行説明として別に保存します。

## Statement types

### specific_commitment

対象、行為、制度変更、数量、期限などの少なくとも一つが明確な約束。

### directional_commitment

政策の方向は示すが、対象・手段・期限の一部が曖昧な約束。

### vision

望ましい都市像や将来像。実施行為が特定できないため、進捗評価はしません。

### supporting_context

経歴、問題認識、政治姿勢、決意、実績説明。公約として採点しません。

## Segmentation rules

- 見出し、箇条書き、独立した文など、資料上の境界を優先する
- 句読点だけを理由に一つの文章を複数公約へ分割しない
- 一つの文に複数の行為があっても、資料上で一体なら最初は一記録として保持する
- 要約から原文にない数値、期限、対象、財源を追加しない
- 判読できない文字を推測で補完しない
- 長い文章は全文転載せず、短い原文部分と資料位置を保存する
- 分割判断に自信がない場合は、資料だけ登録し、公約レコードを作らない

## Field rules

### original_text

資料にある短い原文。要約文や解釈を書かない。

### source_location

ページ、候補者欄、見出し、段落など、第三者が同じ箇所を確認できる位置。

### baseline / target / deadline

資料に明示された場合だけ記録する。任期満了日を暗黙の期限として補わない。

### funding_statement

財源、予算規模、費用負担が明示された場合だけ記録する。「既存予算で対応」等も原文にない場合は補わない。

### controllability

自治体単独で実行できるか、国・県・議会・民間との共同が必要かを示す。不明な場合は `not_assessable` とする。

### assessability

- `assessable`: 進捗判定に必要な対象・行為・根拠がある
- `partially_assessable`: 一部だけ検証できる
- `not_assessable`: 理念、背景説明、または必要条件が不足

### progress_state

実行資料、予算、事業、KPI、公式説明へ接続するまで `not_assessable` とする。選挙公報に掲載された事実だけで `not_started` と判定しない。

## Mandatory safety rules

- 理念と背景説明は `not_assessable` 以外にしない
- 政策思想の賛否を採点しない
- 公約変更を自動的に失敗と判定しない
- 外部要因と自治体権限を確認せず成果を首長へ帰属しない
- 原文、要約、解釈、進捗評価を別項目にする
- 不明・未登録・未評価をゼロや未達へ変換しない

## Current Kitakyushu status

2023年北九州市長選挙の公式選挙公報は資料単位で登録済みです。候補者欄は政策方向と経歴・決意を含む文章であり、独立した公約境界の人手レビューが必要です。

選挙公報については、現時点でも個別公約レコードを作成せず、進捗評価の対象としません（候補者マニフェスト側で登録した公約と重複させないため）。

2026-11-17の追跡探索で、候補者本人の公式サイト（takeuchi-kazuhisa.com）の現存と、Wayback Machine に選挙期間中（2023年1月11日時点）の保存コピーが存在することを確認し、出典として登録しました（`kitakyushu-mayor-candidate-2023-official-site`、`kitakyushu-mayor-candidate-2023-official-site-archive`）。同日、政策PDF（v13）の保存コピー（`kitakyushu-mayor-candidate-2023-manifesto-v13-archive`）を実ブラウザで開き、「7つの基本政策」の全文（7本柱・小項目34件）を原文のまま取得・照合しました。候補者公式サイトを主文書とする分割レビュー（`manifesto-review-jp-local-401005-2023-v13`）で小項目の境界を確認し、公約レコード34件を作成しました。原典は2023年1月11日時点のv13であり、同日保存の旧版と2023年1月31日保存のV15が存在します。V15との差分は未検証であり、v13を最終版とは扱いません。進捗状態は、令和6年度行政評価の登録済み事業へ具体的に接続できた6件のみ `in_progress` とし、残り28件は `not_assessable` のままです。事業との接続は文言・内容に基づく推定であり、確信度は low / inferred を上限とします。選挙公報候補者欄の分割は、引き続き `manual_review_required` です。

## Current Fukuoka City status

2022年福岡市長選挙の高島宗一郎候補の公約については、公約レコード6件を作成しました（探索記録 `manifesto-source-search-fukuoka-city-2022`）。

候補者本人の公式サイト（takashima-soichiro.com）の現行ページは当選後の政策紹介であり、2022年11月2日に発表された選挙公約（「一緒に福岡の未来へ種をまこう」、6本柱）の原文ではありません。当選後の政策方針は公約原文の代替にならないため、原典としては扱いません。Wayback Machine における同ドメインの保存は2026年7月24日分から始まっており、選挙期間中の保存コピーは存在しません。選挙当時の公式ブログ（LINEブログ）の保存コピーを実ブラウザで確認したところ、2022年11月の記事は3件のみで、公約発表に関する記事は投稿されていませんでした。

公約本文は、選挙ドットコム記事（2022年11月16日）の保存コピー（`fukuoka-city-mayor-manifesto-2022-go2senkyo-archive`）が、候補者ホームページに掲載された公約の全文（6本柱・各柱1段落）を原文引用していたことから取得しました。見出し6本は選挙公報（`fukuoka-city-mayor-election-2022-bulletin`）・西日本新聞（2022年11月7日）・いい政治ドットコムの記載と照合済みです。原文が候補者ホームページ自体の保存コピーではなく第三者記事経由の引用であるため、公約レコードの `confidence` は `medium` とし、来歴を各レコードの証拠パケットに明記しています。2022年11月2日の記者発表配布資料そのものの保存は見つかっていません。
