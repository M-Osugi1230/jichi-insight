## Final go / no-go gates

正式なPublic betaへ進むには、最低限次をすべて満たします。

1. 本番CI、build、deployment、Production Smokeが成功
2. 公開対象の全数値に一次資料とEvidence Packetがある
3. 利用規約、プライバシー、免責、ライセンスが確定
4. 訂正受付と障害対応を本番で試験
5. 主要画面のモバイル・キーボード・読み上げ・Lighthouse監査を完了
6. 外部レビューと重大表現の法務確認を完了
7. 公開責任者が公開境界と未収録範囲を承認

## Current recommendation

現状は技術的には公開済みで、公開サイトの配信確認も成功しています。ただし、正式なPublic betaではなく、公開前レビュー用のpre-alpha / release candidateとして扱います。Phase 9全38県のReviewed化を正式公開の必須条件にはせず、まず9地域拠点の公開境界を固定したうえで、法務、アクセシビリティ、訂正運用、障害対応の最終ゲートを閉じる方針とします。
