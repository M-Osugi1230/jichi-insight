# 大阪府 Reviewed data

## Current scope

大阪クラスター（Issue #763）の段階1（Issue #764）として、
基盤情報（首長・計画）と財政を収録しています。

- 令和8年度（2026年度）当初予算（成立後）: 一般会計 3,921,606,338千円、
  府税 1,700,082,000千円（いずれも千円精度。第1号議案は令和8年2月定例会で
  2026年3月24日に原案可決）
- 普通会計決算 FY2022〜FY2024: 17指標×3年（総務省「都道府県決算カード」と
  総務省「財政状況資料集」の2系統で全指標が一致し、検算済み。
  FY2024の見出し値は大阪府公式の府債IR資料でも確認）
- 計画: 副首都ビジョン（大阪府・大阪市共同、2017年策定・2023年3月改定版）の
  レビュー。期間型の総合計画は現行になく、実施層は毎年度の
  「府政運営の基本方針」と第2部の「知事重点事業」であることを記録

## Important distinction

- 普通会計は一般会計と一部の特別会計を再構成した統計上の会計であり、
  府が公表する一般会計決算額とは一致しません。両者を同一系列として
  扱いません。
- 当初予算は成立後の額のみを収録し、予算案段階の額は収録しません。
- 知事の現任期（2023年4月9日〜2027年4月8日）は、府公式FAQの
  日単位の明記（「令和5年4月9日から令和9年4月8日」）と府選挙管理委員会の
  任期満了一覧で確定しています。2026年2月8日の出直し選挙（退職の申立てに
  伴う選挙、当選 3,024,106票）で再選された後も任期の期は変わらないため、
  新規の任期レコードは作成していません（経緯は知事 term の証拠パケットに
  記録）。府公式プロフィールの略歴は「第二期」までの記載です。
