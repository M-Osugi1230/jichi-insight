# 北海道 Reviewed data

## Current scope

北海道クラスター（Issue #736）の段階1（Issue #737）として、
基盤情報（首長・計画）と財政を、段階2（Issue #742）として
重点事業（施策）を収録しています。

- 令和8年度（2026年度）当初予算（成立後）: 一般会計 3,168,109,306千円、
  道税 714,862,942千円（いずれも千円精度）
- 普通会計決算 FY2022〜FY2024: 17指標×3年（総務省「都道府県決算カード」と
  総務省「財政状況資料集」の2系統で照合し、北海道公式「普通会計決算の状況」
  でも見出し値を確認、検算済み）
- 計画: 北海道総合計画（2024年7月策定、2024年度から概ね10年間）のレビュー
- 重点事業: 令和7年度基本評価（政策評価）の対象121施策から、総合計画の
  3つの基本方向を巡回する掲載順の規則で10施策を選定して登録
  （選定根拠は data/catalog/hokkaido_priority_project_selection.json）。
  金額は基本評価調書冒頭の施策予算額（令和5〜7年度、当初予算ベース）、
  評価は道の総合判定（4段階）のみを収録し、独自評価はしていません

## Important distinction

- 普通会計は一般会計と一部の特別会計を再構成した統計上の会計であり、
  道が公表する一般会計決算額とは一致しません。両者を同一系列として
  扱いません。
- 当初予算は成立後の額のみを収録し、予算案段階の額は収録しません。
- 知事の現任期（2023年4月23日〜2027年4月22日）は、道選管・道庁の公式
  ページに日単位の明記が確認できなかったため、前任期満了日
  （2023年4月22日）の公式公表と公職選挙法第259条ただし書の起算方法の
  組み合わせで確定しています（根拠は証拠パケットに明記）。
