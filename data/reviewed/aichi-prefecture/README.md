# 愛知県 Reviewed data

## Current scope

愛知クラスター（Issue #707）の段階1（Issue #710）として、
基盤情報（首長・計画）と財政を収録しています。

- 令和8年度（2026年度）当初予算（成立後）: 一般会計 3,222,441,000千円、
  県税 1,324,300,000千円（いずれも千円精度）
- 普通会計決算 FY2022〜FY2024: 17指標×3年（総務省「都道府県決算カード」と
  愛知県「財政状況資料集」の2系統で照合し、検算済み）
- 計画: あいちビジョン2030（2020年11月策定、2021〜2030年度）のレビュー

## Important distinction

- 普通会計は一般会計と一部の特別会計を再構成した統計上の会計であり、
  県が公表する一般会計決算額とは一致しません。両者を同一系列として
  扱いません。
- 当初予算は成立後の額のみを収録し、予算案段階の額は収録しません。
